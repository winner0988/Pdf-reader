# 注重隱私的桌面端 PDF 閱讀與編輯器：完整開發規格書 v3.0

## 本版（v3）更新摘要
這一版把 grilling 過程中定案的細節併回規格書。詳細決策理由、取捨與詞彙表，請參考隨附的 CONTEXT.md 與 docs/adr/ 底下的 6 條 ADR。
- 底層引擎確定為 MuPDF，不再是三選一（ADR 0003）
- 表單腳本沙盒確定需要，精確定義了沙盒邊界（ADR 0001）
- 遠端資源信任機制確定為內容雜湊比對，跨次保留、內容一變即失效（ADR 0002）
- 新增「文件識別碼」共用機制，機敏標記與密碼記憶共用同一套識別
- 機敏文件防護範圍確定只套用手動標記的文件，標記存在 PDF 中繼資料裡（ADR 0004）
- 新增密碼記憶功能，交由系統憑證庫管理（ADR 0006）
- 批次處理範圍確定為四項操作，且可在背景／系統列繼續執行（ADR 0005）
- OCR 語言包開放使用者自選；崩潰復原改為每次編輯動作即存

---

## 1. 核心框架與系統維護
- **Tauri (Rust / Web)**：首選框架。後端使用 Rust，提供極高的記憶體安全性與極小的執行檔體積，能透過作業系統層級嚴格限制應用程式的網路存取權限。
- **Electron / Qt**：替代方案。Electron 需嚴格鎖定 Node.js 網路模組；Qt 則適合追求極致效能的純原生 C++ 應用程式。
- **作業系統關聯**：支援在安裝時註冊作業系統設定，允許使用者右鍵選擇「使用此應用程式開啟」，並支援設為系統預設 PDF 閱讀器。
- **無追蹤更新**：捨棄帶有遙測性質的自動更新服務。只有使用者在設定頁按下「檢查更新」時，才由主行程向 GitHub Releases API 查詢最新版本；不自動檢查、不自動下載或安裝，絕不夾帶或回傳任何硬體或使用者識別碼（詳見 ADR 0009）。

## 2. 處理引擎與效能最佳化
- **底層引擎**：採用 MuPDF 作為唯一的底層引擎，涵蓋渲染、編輯與表單腳本沙盒三項需求，並有現成 Rust 綁定可與 Tauri 後端整合（詳見 ADR 0003）。授權為 AGPLv3 或另購商業授權；因本專案僅供個人使用、不對外散布，此授權條款不構成限制。（曾考慮 pdf-lib：純 JS，不具渲染與腳本執行能力；PDFium：渲染精確，但編輯能力有限、無內建表單腳本引擎，需搭配額外函式庫——兩者皆因此排除。）
- **OCR 引擎（光學文字辨識）**：整合 Tesseract OCR（開源、可完全離線執行），為掃描件（無文字圖層的圖片型 PDF）產生隱藏的可搜尋文字層，否則掃描件無法被全文搜尋找到。開啟掃描件時自動執行；語言包在設定中由使用者自行選擇安裝，不綁定固定語言。
- **虛擬滾動與懶加載**：針對高達數千頁或數百 MB 的文件，實作僅渲染目前視窗可見頁面的機制，避免記憶體溢出（OOM）或程式卡頓。
- **硬體加速**：底層渲染引擎需能調用本機獨立顯卡或內顯進行圖形運算與字體抗鋸齒渲染，有效降低 CPU 負載。

## 3. 隱私與安全核心機制
- **完全離線運行**：軟體預設不連網、不串接任何外部 API，無雲端同步功能。唯一的例外是使用者手動按下的「檢查更新」（見 §1、ADR 0009）。所有讀取、寫入、壓縮與轉存皆在本地 RAM 與硬碟中完成。
- **無遙測與追蹤**：程式碼中絕對禁止包含 Google Analytics、Sentry 等任何使用者行為追蹤或崩潰回報模組。
- **外部連結攔截**：使用者點擊文件內超連結時，系統必須攔截並跳出警告視窗，顯示完整 URL 要求確認，防止瀏覽器開啟時洩漏 IP 位址。
- **表單腳本沙盒**：PDF 內嵌 JavaScript 預設停用，/OpenAction、/AA（Additional Actions）等開檔即自動觸發的動作一律停用，不受下述例外涵蓋。唯一例外是表單腳本沙盒：僅在使用者主動與表單互動（如輸入、切換欄位）時才啟動，只能讀寫當前文件的表單欄位並觸發重新計算，不得發出網路請求、存取檔案系統或啟動外部程式（詳見 ADR 0001）。
- **遠端資源載入防護與信任機制**：PDF 內部所有遠端資源引用（圖片、字型、串流內容）預設一律封鎖，偵測到時於介面明確提示，防止「PDF 追蹤信標」洩漏 IP 與開檔時間。使用者可以針對單一文件手動選擇信任，允許該文件的遠端資源載入；信任狀態以文件內容雜湊值為依據，跨次啟動保留，內容一旦變動即失效（詳見 ADR 0002）。「信任後載入」延後實作（ADR 0009）：在另立 ADR 之前，遠端資源一律只偵測、封鎖、提示。
- **渲染引擎行程隔離**：將 PDF 解析與渲染邏輯（MuPDF）隔離在獨立的低權限行程中執行，與主應用程式行程分離。即使惡意構造的 PDF 觸發底層函式庫的記憶體漏洞，影響也僅侷限於沙盒行程內，無法進一步存取檔案系統或使用者資料。
- **文件識別碼**：任何需要「跨次啟動、搬移改名都不失效」地識別同一份 PDF 的功能（機敏標記、密碼記憶），都透過寫入該 PDF 中繼資料中的一個應用程式產生的識別碼來達成，而非依賴檔案路徑或內容雜湊。這與上述的信任機制刻意不同——信任必須在內容改變時失效，因此仍以內容雜湊為準；文件識別碼則是文件本身持久的屬性，編輯內容不影響它。
- **中繼資料清除**：提供「隱私匯出」功能，一鍵抹除 PDF 的作者、軟體版本、作業系統、GPS、修改時間及文件識別碼等數位足跡；產生的匯出副本因此不會繼承機敏標記或密碼記憶，原始工作檔案則不受影響。
- **檔案加密與權限（含密碼記憶）**：支援 AES-256 加密，可設定「開啟密碼」與「權限密碼」（限制列印、複製文字或修改內容）。密碼記憶委託給作業系統原生憑證庫（Windows Credential Manager / macOS Keychain），以文件識別碼為查找鍵，不由本應用程式自行儲存密碼明文；使用者仍可針對單一文件選擇不記住密碼（詳見 ADR 0006）。
- **本地數位簽章**：支援載入本機憑證檔（如 .pfx、.p12）進行文件簽署與驗證，確保文件未被竄改，驗證過程完全離線。
- **安全遮蔽**：針對塗黑或刪除的敏感文字與圖片，必須從 PDF 二進位代碼中徹底移除，防止透過反組譯還原。
- **機敏文件與系統層級外洩防護**：系統層級外洩防護預設不套用於所有 PDF，只套用在使用者手動標記為「機敏」的文件（標記依附在文件識別碼上，搬移改名不失效）。保護內容包括：剪貼簿保護（避免複製內容被作業系統雲端剪貼簿同步上傳，例如 Windows 11 剪貼簿歷程雲端同步）、縮圖快取控制（停用系統對機敏 PDF 的縮圖預覽，改顯示使用者自訂的通用圖示）、最近使用檔案清單（預設僅記錄檔名而非完整路徑、保留 20 筆，提供一鍵清除與「不記錄此檔案」模式）。設定中提供「信任與機敏管理」清單，可檢視並取消個別文件的信任或機敏標記（詳見 ADR 0004）。

## 4. 文字編輯與字體模組
- **文字編輯功能**：支援在頁面任意處新增文字方塊，可更改字型、大小、顏色、粗細與對齊方式。
- **完全本地字體**：程式僅掃描並讀取使用者作業系統本機已安裝的字型，嚴禁連線至網路字體庫（如 Google Fonts 或 Adobe Fonts）。
- **字體子集化嵌入**：寫入新文字時，僅將該文字用到的「字型輪廓」嵌入 PDF 檔案中，確保傳送給他人時不會亂碼，同時避免檔案體積暴增。

## 5. 圖片處理模組
- **圖片編輯功能**：支援載入本機圖片（JPG/PNG），並在頁面上自由拖曳位置、縮放大小及旋轉。
- **自動 EXIF 清除**：載入圖片寫入 PDF 前，程式必須在背景自動抹除圖片的 GPS 座標、相機型號與拍攝時間等隱私數據。
- **本地圖片壓縮**：圖片的編碼與壓縮必須在本地端完成，絕不依賴雲端壓縮服務。

## 6. 閱讀、標記與互動模組
- **基礎閱讀與管理**：頁面縮放、書籤導覽、全文搜尋（建立本地索引，含 OCR 產生的隱藏文字層）、深色模式。支援插入、刪除、旋轉頁面順序與拆分/合併 PDF。
- **註解標記**：提供螢光筆、手繪線條、自訂印章等基礎工具。
- **互動表單填寫**：支援讀取與填寫帶有輸入框、核取方塊的標準 PDF 表單，並支援將表單「扁平化」鎖死成不可修改的靜態內容。
- **本地崩潰復原**：實作本地端的差異化暫存檔機制，每次編輯動作即存檔。若編輯途中斷電或當機，下次開啟時將提示本地還原，無需依賴雲端備份。

## 7. 格式轉換與批次處理
- **格式匯出**：支援將 PDF 內容匯出為 Word（.docx）、純文字（.txt）、圖片（PNG/JPG，逐頁匯出）等常見格式，方便內容再利用。
- **格式匯入／建立 PDF**：支援將常見文件格式（如 Office 文件、圖片）透過本地轉換直接建立為 PDF，取代雲端轉檔服務常見的「上傳後轉檔」流程，避免文件內容外流至第三方伺服器。
- **批次處理佇列**：範圍固定為中繼資料清除、EXIF 清除、浮水印加註、加密四項操作，支援一次選取多個檔案排入佇列批次執行，並提供完成報告。佇列啟動後可關閉主視窗，於背景／系統列圖示繼續執行至完成；此背景執行嚴格限定在使用者主動觸發的批次工作進行中，佇列清空即自動結束，不隨開機啟動，與「無遙測」原則不衝突（詳見 ADR 0005）。
