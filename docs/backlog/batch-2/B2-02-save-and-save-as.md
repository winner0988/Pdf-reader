- **需求 ID**：規格 §4–§6（所有編輯功能的前提）；ADR 0013
- **負責角色**：核心 agent（寫出與原子取代）＋前端 agent（未儲存標示與詢問）
- **相依**：B2-01（ADR 0013 已接受）

## 目標
有變更的文件可以儲存（覆寫原檔）或另存新檔；關閉有未儲存變更的分頁或視窗時會詢問。

## 範圍
- 依 ADR 0013 寫出：暫存檔 → worker 以寫入 handle 寫入 → 主行程確認後原子取代。
- 另存新檔對話框由主行程顯示（`IFileSaveDialog`，與 #86 的開啟對話框相同：不加入 Windows 的「最近使用的項目」）；路徑不進前端。
- `Ctrl+S`（儲存）、`Ctrl+Shift+S`（另存新檔）；「⋯」選單對應項目。
- 分頁與視窗標題標示未儲存（例如檔名前的 `•`）。
- 關閉分頁、關閉視窗、以第二次啟動開啟同一個檔案時：詢問「儲存／不儲存／取消」。
- 錯誤：唯讀檔案、磁碟空間不足、檔案被其他程式鎖住、原檔在開啟後被其他程式修改（比對大小與修改時間）時，說明原因並保留變更。
- 存檔後：最近開啟的檔案（#73）更新；另存後分頁指向新檔案。
- 以 B2-01 的旋轉指令作為測試用的編輯（本卡不新增編輯 UI）。

## 不做什麼
- 具體的編輯功能（B2-05 起）；自動存檔與崩潰復原（B2-13）；存檔時加密（另開卡）。

## 可動的模組
- `src-tauri/src/`（存檔命令、另存對話框、原子取代）、`crates/worker_host`、`crates/pdf_worker`
- `crates/ipc_contract`（存檔的命令與事件）、`src-tauri/capabilities/`、`src-tauri/build.rs`、`scripts/ci/check-security-config.mjs`
- `src/features/tabs/`、`src/features/shell/`、`src/i18n/zh-TW.ts`

## 驗收情境
- 假設旋轉第 1 頁後另存新檔，當重新開啟新檔，則第 1 頁已旋轉，原檔不變。
- 假設寫入途中失敗（模擬磁碟已滿），則原檔的內容與修改時間都不變，畫面說明原因，變更仍在。
- 假設有未儲存的變更，當關閉分頁，則詢問；選「取消」時分頁不關閉。
- 假設原檔在開啟後被其他程式修改，當按下儲存，則提示改用另存新檔，不覆寫。

## 必跑測試
- Rust：原子取代、寫入失敗時原檔不變、handle 只能寫入暫存檔。
- 前端：未儲存標示、關閉時的詢問。
- E2E：另存新檔（以 UI Automation 回答系統對話框，比照 `tests/e2e/file-dialog.ps1`）後重新開啟。

## 資安限制
- 前端永遠拿不到路徑；另存對話框只在主行程。
- worker 只拿到暫存檔的寫入 handle；不能讀取、刪除或列舉其他檔案。
- 不經使用者確認不得覆寫任何檔案；另存到原檔時也視為覆寫。
