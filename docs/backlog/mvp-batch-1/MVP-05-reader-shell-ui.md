- **需求 ID**：MVP-R11
- **負責角色**：前端 agent
- **相依**：MVP-01、UX-01

## 目標
依 UX-01 的畫面地圖做出閱讀器外殼（先接假資料），讓後續功能卡直接往裡面填功能。

## 範圍
- 版面：工具列（開啟、縮放、旋轉、搜尋、設定）、可收合側欄（目錄分頁；縮圖分頁先占位）、中央頁面畫布、狀態列（頁碼／總頁數、縮放比例）、安全警示橫幅區域。
- 狀態：空狀態、載入中、錯誤（損毀、非 PDF、加密不支援、worker 崩潰）、已開啟（假資料）。
- 深色模式：預設跟隨系統，可手動切換（本卡不做持久化設定）。
- 快捷鍵框架：集中註冊，可列在說明面板；先放 `Ctrl+O`、`Ctrl+F`、`Ctrl+=`／`Ctrl+-`、`Ctrl+0` 的占位行為。
- UI 文字集中在單一字串檔（繁中）。
- 基本無障礙：按鈕有可讀名稱、可純鍵盤操作、焦點可見。

## 不做什麼
- 真實 PDF 渲染、搜尋邏輯、設定頁內容、縮圖、設定持久化。

## 可動的模組
- `src/`（components、features/shell、i18n、styles）

## 驗收情境
- 四種狀態都能在開發模式下以假資料切換並正確顯示。
- PR 附上淺色與深色模式截圖（依 UX-01 的截圖清單）。
- 只用鍵盤可以走遍工具列與側欄的所有控制項。
- 視窗寬度從 800px 到 2560px，版面不破。

## 必跑測試
- Vitest + Testing Library 元件測試：四種狀態、快捷鍵註冊、深色模式切換。
- `pnpm lint`、`pnpm typecheck`

## 資安限制
- 不得載入任何外部資源；字型與圖示必須打包在本地。
- 不得使用 `dangerouslySetInnerHTML` 或任何 HTML 解譯方式顯示來自 PDF 的字串（目錄標題、連結、檔名等之後都來自不可信的 PDF）。
