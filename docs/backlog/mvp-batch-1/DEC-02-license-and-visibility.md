- **需求 ID**：ADR 0003（授權段落）
- **負責角色**：負責人
- **相依**：無；**必須在任何形式的發布（含把安裝檔給別人）或 repo 改為公開之前完成**

## 目標
確認 MuPDF 的 AGPLv3／商業授權對本專案的義務，並決定本專案自己的授權與 repo 可見性。

## 背景
ADR 0003 的前提是「僅供個人使用、不對外散布」。但只要把安裝檔交給任何其他人，或把 repo 公開，AGPL 的原始碼提供義務就會生效；若之後想商業化，則需要向 Artifex 購買商業授權。

## 範圍
回答並記錄以下問題：
1. repo 會一直維持私有嗎？
2. 會不會把安裝檔給其他人（包含朋友、同事）？
3. 未來有沒有商業化的可能？
4. 依以上答案，本專案採用的授權（例如 AGPL-3.0-or-later，或維持不公開、不散布）。

產出：
- 一條新的 ADR（授權與散布），補充或取代 ADR 0003 的授權段落。
- 若決定公開或散布：在根目錄加入 `LICENSE`，並在 README 註明第三方授權。
- 提供 MVP-13 需要的「允許授權清單」（cargo-deny 的 `licenses.allow`）。

## 不做什麼
- 不購買授權、不更換 PDF 引擎（若要換引擎需另立 ADR，成本極高）。

## 可動的模組
- `docs/adr/`、`README.md`、`LICENSE`（新增）

## 驗收情境
- 新 ADR 狀態為「已接受」，內容說明散布範圍與對應義務。
- 若公開或散布：`LICENSE` 存在，且與 MuPDF 授權相容。

## 必跑測試
- CI `Guardrails`（ADR 檢查）通過。

## 資安限制
- 無。
