# 6. 快捷鍵與無障礙

[回到目錄](README.md)

app 裡按 `Ctrl+/`，或「⋯」→「快捷鍵」，可以看到這張表。

## 快捷鍵

| 動作 | 按鍵 |
|---|---|
| 開啟檔案 | `Ctrl+O` |
| 儲存／另存新檔 | `Ctrl+S`／`Ctrl+Shift+S` |
| 復原／重做 | `Ctrl+Z`／`Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| 關閉分頁 | `Ctrl+W`；焦點在分頁上時 `Delete` |
| 複製選取的文字 | `Ctrl+C` |
| 列印 | `Ctrl+P` |
| 下一個／上一個分頁 | `Ctrl+Tab`（或 `Ctrl+PageDown`）／`Ctrl+Shift+Tab`（或 `Ctrl+PageUp`） |
| 搜尋 | `Ctrl+F` |
| 在所有文件中搜尋 | `Ctrl+Shift+F` |
| 下一筆／上一筆結果 | 搜尋列中 `Enter`／`Shift+Enter`；任何時候 `F3`／`Shift+F3` |
| 放大／縮小 | `Ctrl+=`（或 `Ctrl++`）／`Ctrl+-`；`Ctrl+滾輪` |
| 符合頁面／實際大小（100%）／符合寬度 | `Ctrl+0`／`Ctrl+1`／`Ctrl+2` |
| 順時針／逆時針旋轉（只改變檢視） | `Ctrl+]`／`Ctrl+[` |
| 跳到頁碼 | `Ctrl+G` |
| 第一頁／最後一頁 | `Home`／`End` |
| 開關側欄 | `F4` |
| 在區域間移動焦點 | `F6`／`Shift+F6`（工具列 → 提示列 → 側欄 → 頁面） |
| 關閉對話框、面板、搜尋列；結束畫筆、印章等工具 | `Esc` |
| 快捷鍵說明 | `Ctrl+/` |

**在縮圖上**

| 動作 | 按鍵 |
|---|---|
| 移動 | `↑`／`↓`、`Home`／`End` |
| 延伸選取／加選 | `Shift`+方向鍵／空白鍵 |
| 全選 | `Ctrl+A` |
| 刪除選取的頁面 | `Delete` |
| 跳到那一頁 | `Enter` |

**在目錄（書籤）上**

| 動作 | 按鍵 |
|---|---|
| 新增書籤（目前頁面） | `Ctrl+B` |
| 重新命名 | `F2` |
| 刪除書籤 | `Delete` |
| 上移／下移 | `Alt+↑`／`Alt+↓` |
| 升級／降級 | `Alt+←`／`Alt+→` |
| 展開／收合 | `→`／`←` |
| 跳到那一頁 | `Enter` |

**選取註解、印章或文字方塊之後**

| 動作 | 按鍵 |
|---|---|
| 移動 1 點／10 點 | 方向鍵／`Shift`+方向鍵 |
| 旋轉自訂圖片 15 度 | `[`／`]` |
| 修改文字方塊 | `Enter` |
| 刪除 | `Delete` |
| 放開 | `Esc` |

焦點在文字欄位（搜尋框、頁碼、表單欄位）時，只有 `Ctrl` 組合鍵與 `Esc` 有作用，其他按鍵留給欄位。用輸入法組字時，按鍵都是輸入法的。

## 只用鍵盤操作

- 所有功能都能只用鍵盤操作，焦點有清楚的外框。
- 頁面區域在 `Tab` 順序中，有焦點時可以用方向鍵與 `PageDown`／`PageUp` 捲動。
- 畫筆以外的放置工具（印章、自訂圖片、文字方塊、安全遮蔽）開著時，按 `Enter` 放在目前這一頁的中央。
- 表單用 `Tab` 在欄位間移動；同一組選項按鈕用方向鍵選擇。
- 目錄用方向鍵移動、`→` 展開、`←` 收合、`Enter` 跳頁。
- 對話框開著時焦點留在對話框裡，關閉後回到原來的按鈕。

## 螢幕閱讀器

- 按鈕都有名稱；狀態列的提示（例如「已儲存。」、作者的限制、文字辨識的結果）會被讀出。
- 畫面分成有名稱的區域：分頁列、工具列、側欄、頁面、狀態列，以及警示橫幅與提示列。
- 頁面上的連結、表單欄位與註解都可以用 `Tab` 走到，並有說明。

## 顯示

- 文字與背景的對比符合 WCAG AA，淺色與深色模式都是。
- Windows 設為減少動畫效果（「設定」→「協助工具」→「視覺效果」→「動畫效果」關閉）時，app 不播放轉場與動畫。
- 視窗最小 800 × 600；很窄時側欄浮在頁面上。
