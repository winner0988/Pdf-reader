# 2. 閱讀

[回到目錄](README.md)

## 畫面

由上到下：分頁列、工具列、提示列（有需要時才出現）、側欄與頁面、狀態列。

- **工具列**（左到右）：「開關側欄」、「開啟」、「上一個位置」、「下一個位置」、頁碼／總頁數、「縮小」、縮放比例、「放大」、「符合寬度」、「符合頁面」、「逆時針旋轉」、「順時針旋轉」；編輯工具（螢光筆、「畫筆」、「新增印章」、「文字方塊」、「安全遮蔽」）；右邊是「搜尋」與「更多」（⋯）。滑鼠停在按鈕上會顯示名稱與快捷鍵。
- **狀態列**：左邊是檔名與文件的狀態（例如「機敏文件」、作者的限制、文字辨識的進度）；右邊是 `第 n / N 頁 · 縮放%`。滑鼠停在連結上時，這裡顯示連結會去哪裡。

## 捲動與跳頁

- 頁面連續往下排；滾輪、觸控板、`PageDown`／`PageUp` 捲動，`Home`／`End` 到第一頁或最後一頁。
- 在頁碼框輸入數字按 `Enter` 跳到那一頁（`Ctrl+G` 把焦點移到頁碼框）。超出範圍時框線變紅，不跳頁。
- 文件內部的連結（例如目錄裡的「第 5 頁」）直接跳頁。
- **回到跳頁前的位置（導覽歷程）**：點擊文件內的連結、目錄、搜尋結果、縮圖、輸入頁碼或跨文件搜尋跳頁時，app 會在跳頁上記錄位置（頁碼、捲動位置與縮放比例）。
  - 按 `Alt+←` 或工具列的「上一個位置」按鈕回到跳頁前的位置；
  - 按 `Alt+→` 或工具列的「下一個位置」前往下一個位置；
  - 亦可使用滑鼠的上一頁／下一頁側鍵（按鍵 3 與 4）；
  - 沒有可前往的位置時按鈕會停用；一般的連續捲動、方向鍵與 `PageDown` 不會記進歷程；
  - 每個分頁各有獨立的歷程（最多 100 筆），只留在記憶體中，關閉分頁時清除；頁面經刪除或移動編輯後，歷程會自動跟隨新頁碼。

## 縮放與旋轉

- 「放大」「縮小」（`Ctrl+=`／`Ctrl+-`），或 `Ctrl+滾輪`（以游標所在的地方為中心）。範圍 25%～800%。
- 「符合寬度」（`Ctrl+2`）讓頁面寬度等於視窗；「符合頁面」（`Ctrl+0`）讓整頁可見；`Ctrl+1` 是實際大小（100%）。這兩種模式在視窗大小改變時繼續生效，直到你自己縮放。
- 開啟文件時是「符合寬度」，但不超過 200%。
- 放大到 200% 以上時，頁面只針對可見區域分塊渲染，放到 400%～800% 也能清晰呈現小字與圖表細節。放得很大時捲動，剛捲到的地方會先以較低的解析度顯示，停下來約十分之一秒後變清晰。
- 「順時針旋轉」「逆時針旋轉」（`Ctrl+]`／`Ctrl+[`）只改變**檢視**，不修改檔案，關閉後不保留。要永久轉動頁面，見[整理頁面](03-editing.md#整理頁面)。

## 側欄：目錄、縮圖、附件與遮蔽

`F4` 或「開關側欄」開關側欄；拖曳邊緣調整寬度。視窗很窄時，側欄浮在頁面上，點一下頁面就關閉。

- **「目錄」**：文件有書籤（目錄）時列在這裡，目前所在的項目有底色。點一下跳到那裡；方向鍵移動，`→` 展開、`←` 收合，`Enter` 跳頁。除了瀏覽，也可以在目錄中新增、重新命名、刪除與調整書籤階層（見[編輯書籤](03-editing.md#編輯書籤)）。
- **「縮圖」**：每頁一張，目前這一頁有外框。點一下跳到那一頁；`↑`／`↓` 在縮圖間移動，`Enter` 跳頁。縮圖也用來整理頁面（見[整理頁面](03-editing.md#整理頁面)）。標記為機敏的文件只顯示頁框與頁碼，不畫出頁面內容（見[機敏文件](05-security-and-privacy.md#機敏文件)）。
- **「附件」**：列出 PDF 裡夾帶的檔案（文件層級或頁面上的附件），顯示名稱、副檔名與宣稱大小。
  - 按「另存…」可將附件存到電腦中；app 永遠不會直接開啟附件。
  - 可以執行的類型（例如 `.exe`、含巨集的 Office 檔、沒有副檔名的檔案）會標示「可執行檔案類型，另存前請確認來源可信」，另存時會彈出「另存可執行檔案」確認對話框，需按「繼續另存」確認。
  - 存下來的檔案會標記為「來自網際網路」，Windows 開啟前會再檢查；存到 FAT32 隨身碟等不支援標記的磁碟時，app 會提醒。
  - 機敏文件的附件存下來之後不在機敏保護內。
- **「遮蔽」**：待遮蔽的範圍清單，包含手動框選與「找出個資…」找到的項目（見[安全遮蔽](05-security-and-privacy.md#安全遮蔽)）。

## 搜尋

1. `Ctrl+F` 或工具列的「搜尋」，頁面右上角出現搜尋列。
2. 輸入文字，停下來後自動搜尋；`Enter` 跳到下一筆，`Shift+Enter` 上一筆（搜尋列關掉後用 `F3`／`Shift+F3`）。
3. 所有結果以黃色標示，目前這一筆有橘色外框；搜尋列顯示「第 n／N 筆」。
4. 「Aa」切換「區分大小寫」（預設不區分）。
5. `Esc` 或 ✕ 關閉搜尋列並清除標示。

結果超過上限時只顯示前面的部分，搜尋列會說明。文字方塊裡的字也找得到。

**掃描的文件**沒有文字可以搜尋，搜尋列會提示；讓 app 辨識文字之後就能搜尋（見下方[掃描頁的文字辨識](#掃描頁的文字辨識)）。

### 在所有文件中搜尋

如果在「設定」中開啟了「本機全文索引」（見[這台電腦上保存的資料](05-security-and-privacy.md#這台電腦上保存的資料)），可以跨文件搜尋開過的檔案內容。

1. 按 `Ctrl+Shift+F`，或工具列「⋯」→「在所有文件中搜尋…」（未開檔時按畫面上的「在所有文件中搜尋…」）。
2. 輸入要搜尋的文字，可勾選「區分大小寫」。
3. 搜尋結果依文件列出，顯示檔名、處數、頁數與前後文字預覽。
4. 點擊結果中的某一頁（例如「第 5 頁」），會在新分頁開啟該文件並跳到那一頁。

機敏文件、有密碼的 PDF、選了「不記錄此檔案」的檔案，以及隨身碟、光碟、網路位置上的檔案不會收錄進索引。檔案被移動或修改時，app 會提示並從索引移除。

## 選取與複製文字

- 在文字上按住拖曳選取；拖到邊緣會自動捲動，可以跨行、跨頁。
- 雙擊選一個詞，三擊選一整行；`Shift`+點擊延伸選取；在文字以外的地方點一下取消。
- `Ctrl+C`，或在頁面上按右鍵選「複製」。每行之間換行；隱藏的控制字元不會被複製。
- 頁面上的右鍵選單是 app 自己的：「複製」、「螢光筆」、「標記為待遮蔽」、「在這裡新增附註…」、「在這裡新增文字方塊…」。

不能選取或複製的情況：

- **掃描頁**沒有文字層，狀態列會說明；辨識文字之後就可以。
- **作者禁止複製**時可以選取，但不會複製，狀態列顯示「文件作者不允許複製此文件的文字」（見[文件權限](05-security-and-privacy.md#文件權限)）。

從**機敏文件**複製的文字不會進入 Windows 的剪貼簿歷程（`Win+V`）與雲端剪貼簿（見[機敏文件](05-security-and-privacy.md#機敏文件)）。

## 掃描頁的文字辨識

掃描的文件是一張張圖片，沒有文字。app 可以在這台電腦上辨識（OCR）掃描頁的文字，辨識好的頁面就能選取、複製、搜尋與畫螢光筆。

- **自動**：預設開啟文件後在背景辨識，從你正在看的頁面開始。狀態列顯示「辨識文字：已完成 / 掃描頁數 頁」與「停止」；停止後已辨識的文字保留。沒有掃描頁的文件什麼都不會發生。
- **手動**：在「⋯」→「設定…」的「文字辨識（OCR）」關閉自動；之後在「⋯」選單選「辨識此文件的文字」。
- 目前這一頁的文字是辨識出來的時候，狀態列顯示「此頁文字由 OCR 辨識，可能有誤」。
- 辨識的結果**只在記憶體中**，不寫進檔案；關閉文件就丟棄。
- 辨識時仍然可以閱讀、縮放與編輯。

### 辨識的語言

app 內附繁體中文與英文的語言資料；繁體中文的資料也認得英文與數字。一次只用一種語言。

其他語言：在「設定」的「辨識的語言」選擇。要用沒有內附的語言，按「匯入語言資料…」選一個 Tesseract 的 `.traineddata` 檔（例如 `deu.traineddata`，上限 64 MB）。app 不會下載任何東西；檔案要自己準備，app 會把它複製到這台電腦的資料資料夾。匯入的語言可以「移除」。

## 比較分頁文字

開啟兩份以上的文件時，可以在工具列「⋯」選單選「與另一個分頁比較文字…」，比對目前分頁與另一個開啟分頁的文字差異（例如同一份合約或文件的不同修訂版本）。

1. 在「⋯」選單點選「與另一個分頁比較文字…」（只有一個分頁時此項目停用並說明；目前文件不允許複製時亦會停用）。
2. 在「比較對象」選取要比對的另一個分頁，點選「開始比較」。
   - 若某些分頁的文件作者不允許複製文字，該分頁在選單中會停用並標註「這份文件的作者不允許複製文字」。
   - 若其他分頁皆不允許複製文字，對話框會明確說明無法進行比較。
3. 比較完成後，面板列出所有文字差異：
   - 每項顯示兩份文件各自對應的頁碼、刪除的文字（紅色刪除線）與新增的文字（綠色底色）。
   - 點選任一差異項目可直接跳到目前分頁的該頁。
   - 文件完全相同或兩份皆無文字時會明確提示；若只有其中一份文件沒有文字（例如未經文字辨識的掃描檔），會特別標示是哪一份文件沒有文字並建議先做文字辨識（OCR）；若有頁面包含 OCR 辨識文字或文字過長截斷，亦會加以標示。
4. 按「匯出純文字…」或「匯出 Markdown…」可將比對結果存成檔案，內容由主行程直接產生，不經前端頁面傳輸。匯出時若任一文件在比對之後曾編輯過，會自動重新比對以確保最新。

若任一文件作者設定為禁止複製文字，app 不會執行比對以尊重權限設定。

## 列印

1. `Ctrl+P` 或「⋯」→「列印…」。
2. 選「列印範圍」：全部、目前頁，或頁碼（例如 `1-3, 5`；可以用 `,`、`、` 或空白分隔，範圍用 `-` 或 `~`）。一次最多 300 頁。
3. 按「繼續」，app 逐頁準備（可以取消），然後開啟 Windows 的列印對話框，在那裡選印表機、份數與方向。

列印不套用檢視用的旋轉與縮放；每一頁依紙張等比例縮放，完整印在一張紙上。作者禁止列印或只允許低解析度列印時，見[文件權限](05-security-and-privacy.md#文件權限)。

## 外觀與深色模式

「⋯」→「外觀」，或「設定…」的「外觀」：「跟隨系統」（預設）、「淺色」、「深色」。

深色模式只改變 app 的介面與頁面周圍的背景，**頁面內容照原樣顯示**，不會反色。
