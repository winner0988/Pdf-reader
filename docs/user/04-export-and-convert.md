# 4. 匯出與轉檔

[回到目錄](README.md)

這一章的功能都**另存一份新檔案**：開著的文件與它的檔案不會改變，新檔案也不會加入最近開啟的檔案（「從檔案建立 PDF」除外，它會在新分頁開啟）。存檔的位置一律由 Windows 的對話框讓你選；選到原來的檔案時，app 會說明並讓你再選一次。

## 匯出

「⋯」→「匯出…」。作者禁止複製時不能用。

| 格式 | 結果 |
|---|---|
| 「純文字（.txt）」 | 一個文字檔 |
| 「Word 文件（.docx，文字與圖片，不保留版面）」 | 文字（保留字型、大小、粗體、斜體與顏色）與圖片依閱讀順序排成段落，每頁一節；欄位、表格與圖片的位置不保留 |
| 「頁面圖片（PNG，每頁一個檔案）」、「頁面圖片（JPG，每頁一個檔案，檔案較小）」 | 選一個資料夾，每頁一個檔案（`<檔名>-p<頁碼>.png`）；解析度 72、150（預設）或 300 dpi |
| 「PDF 檔案（選的頁面存成一個新檔案）」 | 選的頁面存成一個 PDF |
| 「PDF 檔案（每幾頁存成一個檔案）」 | 拆成很多個 PDF，在旁邊的框填每個檔案的頁數（預設 10）；選一個資料夾 |

- **頁面**：全部、目前頁或頁碼（例如 `1-3, 5`）。文字與圖片一次最多 1,000 頁；拆分最多 1,000 個檔案。
- 按「匯出…」選位置。匯出時可以按「停止」。
- **從縮圖**：選好頁面（`Ctrl`／`Shift` 多選），按右鍵選「將選取的頁面另存為新檔…」。
- 加密的文件不能存成 PDF 檔案：拆出來的檔案不會再有作者設定的保護。

## 匯出註解摘要

把文件中的註解依頁碼與閱讀順序列成純文字或 Markdown 檔案。「⋯」→「匯出註解摘要…」（作者禁止複製的文件無法使用，選單標示「作者不允許」）。

- 螢光筆列出標示底下的文字，附註與文字方塊列出文字內容，手繪線條與印章列出在第幾頁。
- 選「格式」：「純文字（.txt）」或「Markdown（.md）」。
- 可勾選「開頭加上檔名」。
- 按「匯出…」選擇位置。
- 文件沒有註解時會顯示「這份文件沒有可以匯出的註解。」，不會存檔。
- 一次最多匯出 10,000 個註解；註解過多時只列出前面的部分，檔案結尾與狀態列會說明。

## 隱私匯出

分享文件之前，另存一份清除中繼資料的副本。「⋯」→「隱私匯出…」，按「選擇位置並匯出…」。

**副本中會清除**

- 文件資訊：作者、標題、主旨、關鍵字、建立與修改的程式、日期
- XMP 中繼資料（可能含有 GPS 位置）
- 應用程式的私有資料、頁面縮圖與修改時間
- 註解的作者與日期（註解本身保留）
- 文件識別碼（換成新的亂數）
- 機敏標記（副本不是機敏文件）

**不會清除，分享前請自行檢查**

- 頁面上的文字與圖片，以及註解的內容
- 圖片本身的 EXIF（例如相片中的 GPS 位置）：用[批次處理](#批次處理)的「清除圖片的 EXIF」
- 附加的檔案、表單欄位的值、書籤

副本中的數位簽章會失效。加密的文件不能隱私匯出。要從頁面上移除看得到的內容，用[安全遮蔽](05-security-and-privacy.md#安全遮蔽)。

## 分享前淨化

另存一份徹底拿掉腳本、動作與隱藏資料的乾淨副本，原檔不變。「⋯」→「分享前淨化…」。已簽章或加密的文件不適用。

- **要清除的項目**（可勾選）：
  - 「動作與 JavaScript（開啟事件、欄位動作、外部執行等）」
  - 「內嵌檔案與附件」
  - 「表單腳本（計算與驗證；保留欄位內容與外觀）」
  - 「XFA 動態表單（僅保留標準 PDF 內容）」
  - 「多媒體內容（影片、聲音、3D）」
  - 「隱藏資料（中繼資料、縮圖、私有應用程式資料、註解作者）」
- **網址連結**：可勾選「保留一般網址連結（http、https、mailto；其他危險 scheme 一律移除）」。
- **註解處理**：「保留註解（不修改註解）」、「移除註解（清除所有非連結、非表單欄位的註解）」、「平面化註解（將註解繪製成頁面內容，不可再編輯）」。
- 按「選擇位置並淨化…」存檔。寫出前會再次掃描，確保無殘留；完成後顯示各類別清除數量的清單。
- **不會清除（分享前請自行檢查）**：
  - 頁面上的文字與圖片內容
  - 圖片本身的 EXIF 中繼資料（請用[批次處理](#批次處理)的「清除圖片的 EXIF」）
  - 隱藏圖層（OCG）中的內容
- 標記為機敏的文件：清除隱藏資料時，淨化後的副本不會帶有機敏標記；沒有清除隱藏資料時，副本仍會帶有機敏標記。

## 頁碼與 Bates 編號

在副本的頁面加上頁碼、Bates 編號或頁首頁尾，原檔不變。「⋯」→「頁碼與 Bates 編號…」。

- **「頁碼」**：
  - 格式：「純數字（1）」、「第 N 頁（第 1 頁）」、「第 N 頁／共 Total 頁（第 1 頁／共 10 頁）」或「自訂前後綴」（可設定前綴與後綴）。
  - 可設定起始號碼與位置（「上左」、「上中」、「上右」、「下左」、「下中」、「下右」）。
- **「Bates 編號」**：
  - 可設定前綴（最多 32 個字元）、位數（1 至 12 位，自動補零）、起始號碼與位置。
- **「頁首與頁尾」**：
  - 6 個位置：頁首左側、頁首中央、頁首右側、頁尾左側、頁尾中央、頁尾右側（每格最多 100 個字元，不支援換行）。
- **「外觀與範圍」**：
  - 字級（點）、文字顏色（黑色、灰色、紅色、藍色）、邊距（點）。
  - 頁面範圍：「全部頁面」、「第一頁以外」、「自訂範圍」（例如 `1-5, 8, 11-13`）。
- **效果預覽**：提供「第一頁標記效果」與「最後一頁標記效果」即時預覽。
- 同一個位置不能放多個標記（會提示衝突錯誤）；請至少啟用一項標記。
- 按「選擇位置並另存新檔…」存檔。
- 加上的字是頁面內容，可被選取、複製與搜尋。有數位簽章的文件，副本中的簽章會失效；加密的文件不適用。

## 加密並另存新檔

把目前的文件以 AES-256 加密，另存成新檔。「⋯」→「加密並另存新檔…」。

- **「開啟密碼」**：沒有的話任何人都能開啟副本。
- **「限制」**：「不允許列印」、「不允許複製文字與圖片」、「不允許修改（包含頁面整理、註解與填寫表單）」。有任何限制時一定要設**「權限密碼」**，而且要與開啟密碼不同。
- 每個密碼都要輸入兩次。

注意：

- **密碼不會被記住，也無法找回**：忘記了就打不開這份副本。
- 「限制」靠閱讀器自行遵守。這個 app 與 Acrobat 都遵守，但有些程式會忽略；要真正保密請設開啟密碼。
- 有數位簽章的文件不能加密（簽章會失效）。已經加密的文件不適用。
- 對話框關閉後，密碼欄位就清空。

## 壓縮圖片並另存新檔

把文件裡的圖片重新編碼成較小的檔案。「⋯」→「壓縮圖片並另存新檔…」。

1. 選「品質」：「高」、「中（建議）」、「低」。
2. 選「圖片的最大尺寸」：「不縮小」，或長邊最多 3000、2000（預設）、1500、1000 像素。
3. 按「選擇位置並壓縮…」。

完成後顯示副本的大小、少了多少，以及重新編碼了幾張圖片。只有變小的圖片才會換掉；掃描的黑白頁面、有遮罩的圖片與線條圖通常不會動。重新編碼的圖片不帶相機的資料（EXIF、GPS）。已加密或有數位簽章的文件不能壓縮。

## 從檔案建立 PDF

把其他檔案轉成一份新的 PDF，在新分頁開啟。沒有開啟文件時按畫面上的「從檔案建立 PDF…」，有文件時從「⋯」選單選同名的項目。

可以用的檔案：

- 圖片（PNG、JPEG、GIF、BMP、TIFF）：可以一次選很多張，依檔名順序排列，一張一頁。
- 網頁（HTML）、純文字（TXT）、SVG、電子書（EPUB）、XPS：一次一個檔案。
- Word（DOCX）、Excel（XLSX）、PowerPoint（PPTX）：一次一個檔案，**實驗性**。

每個檔案最多 64 MB，一次最多 200 個檔案。按「選擇檔案…」選來源檔，再選新 PDF 的位置。

- **Office 文件是實驗性的**：轉換用的是 PDF 引擎內建的功能，不是 Office；版面、字型、圖表和格式可能和原本不同。重要的文件請在轉好後逐頁檢查。
- 轉換時**不連網**：網頁裡的圖片、樣式表與其他遠端資源都不會載入，指令碼也不會執行，所以網頁可能少了圖片或樣式。
- 來源檔的作者、標題、日期不會帶進 PDF；圖片只留下畫面。
- 轉換在隔離的程序中進行：損壞或惡意的檔案只會讓這次轉換失敗。

## 批次處理

對很多個 PDF 做同一件事，每個檔案產生一份副本，放在你選的資料夾。原本的檔案不會改變，資料夾裡已有的檔案也不會被覆寫。「⋯」→「批次處理…」（沒有開啟文件時也能用）。

**要做的事**（一次選一種）：

| 選項 | 說明 |
|---|---|
| 「清除中繼資料（與「隱私匯出」相同）」 | 見[隱私匯出](#隱私匯出) |
| 「加密（AES-256，與「加密並另存新檔」相同）」 | 欄位與規則同[加密並另存新檔](#加密並另存新檔) |
| 「清除圖片的 EXIF（相機、拍攝時間與地點等）」 | 只清除圖片裡的資訊，圖片不重新編碼，看起來完全一樣。文件本身的作者、標題等不在其中 |
| 「分享前淨化（清除主動內容與隱藏資料，與「分享前淨化」相同）」 | 另存一份拿掉腳本、動作、附件與隱藏資料的副本，見下方 |
| 「浮水印（在每頁畫上文字或圖片）」 | 見下方 |
| 「壓縮圖片（與「壓縮圖片並另存新檔」相同）」 | 重新編碼文件中的圖片為較小檔案，見下方 |
| 「頁碼與 Bates 編號（與「頁碼與 Bates 編號」相同）」 | 加上頁碼、頁首頁尾或跨檔案連號的 Bates 編號，見下方 |

**浮水印**

- 「類型」：「文字」（最多 100 個字元，字體大小 8～200 點，文字顏色）或「圖片」（PNG 或 JPEG，寬度 16～1200 點；開始時才選圖片）。
- 「不透明度（%）」：5～100%，底下的頁面看得見。
- 「方向」：「水平」或「對角線（從左下到右上）」。「位置」：「置中」、「靠上」、「靠下」。
- 「套用頁面」：「所有頁面」、「只有第一頁」、「第一頁以外」。
- 浮水印畫成頁面內容，其他閱讀器也看得到、搜尋得到。有數位簽章的檔案，副本裡的簽章不會成立。

**壓縮圖片**

- 選擇「品質」（高、中、低）與「圖片的最大尺寸」（不縮小，或長邊最多 3000、2000、1500、1000 像素）。
- 每個檔案產生一份 `<檔名>（已壓縮）.pdf` 副本。只有變小的圖片才會替換，重新編碼的圖片不帶相機資料（EXIF、GPS）。
- 有數位簽章的檔案會失敗（壓縮後簽章不會成立），有密碼的檔案會略過。一個檔案圖片過多逾時，其餘圖片保持原樣，結果仍算完成。

**分享前淨化**

- 設定要清除的項目、保留一般網址連結與註解處理（選項同[分享前淨化](#分享前淨化)）。
- 每個檔案產生一份 `<檔名>（淨化副本）.pdf` 副本。
- 有數位簽章的檔案會失敗（淨化後簽章不會成立），有密碼的檔案略過。
- 結果只顯示每個檔案是否完成，不列出各項目清除數量。清除隱藏資料時，機敏文件的副本不再是機敏文件。

**頁碼與 Bates 編號**

- 設定頁碼、Bates 編號、頁首頁尾與外觀範圍（選項同[頁碼與 Bates 編號](#頁碼與-bates-編號)）。
- 每個檔案產生一份 `<檔名>（頁碼與 Bates）.pdf` 副本。
- **Bates 編號跨檔案依序連號**：開始時設定的起始號碼在處理多個檔案時依序遞增；失敗或略過的檔案不佔用號碼；完成後對話框與報告顯示該檔案分配到的 Bates 號碼範圍（例如 `DOC-000001` 或 `DOC-000001～DOC-000010`）。
- 檔案的 Bates 編號超出位數上限時該檔案會失敗；檔案沒有要加標記的頁面或頁面範圍超出其頁數時該檔案會失敗；有數位簽章的檔案會失敗；有密碼的檔案略過。

**開始**

1. 按「選擇檔案並開始…」，選 PDF（可以多選），再選放副本的資料夾。
2. 對話框列出每個檔案的狀態：等待中、完成、失敗（原因）、略過。「停止」在目前的檔案做完後停下。
3. 做完後按「完成」。

- 一次最多 500 個檔案，一個接一個處理；一個失敗不影響其他的。
- **有密碼的 PDF 會略過**：批次處理不詢問密碼。
- **處理中可以關閉視窗**：視窗隱藏，批次在系統列（右下角）繼續，圖示的選單可以「顯示視窗」或「停止批次處理」。做完後在資料夾留一份 `批次處理報告.txt`，跳出「批次處理完成」的訊息，按「確定」後程式結束。
- 加密用的密碼在開始與關閉時清空，報告裡沒有密碼。
