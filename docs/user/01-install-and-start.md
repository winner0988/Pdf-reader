# 1. 安裝與開始使用

[回到目錄](README.md)

## 安裝

1. 下載安裝檔 `PDF-Reader_<版本>_x64-setup.exe` 與同名的 `.sha256` 檔。
2. **核對檔案沒有被調包**：在下載的資料夾開啟 PowerShell，執行

   ```powershell
   Get-FileHash -Algorithm SHA256 '.\PDF-Reader_<版本>_x64-setup.exe'
   ```

   顯示的值要與 `.sha256` 檔（或發行說明）中的相同；大小寫不同沒關係。
3. 執行安裝檔。安裝檔目前沒有程式碼簽章，Windows 會顯示「Windows 已保護您的電腦」，發行者是「不明的發行者」。確認過上一步的雜湊值後，按「其他資訊」→「仍要執行」。
4. 安裝精靈的語言依 Windows 的語言（繁體中文或英文）。安裝需要系統管理員權限：程式裝在 `C:\Program Files\PDF Reader\`，一般權限的程式無法替換它的檔案。

安裝檔不會下載任何東西。如果電腦沒有 WebView2（Windows 10，或被移除了），安裝檔與 app 都會說明，請先自行安裝 Microsoft Edge WebView2 Runtime。

### 更新與解除安裝

- **更新**：安裝新版本的安裝檔即可，設定與「設為預設」的選擇都會保留。app 不會自動更新；要知道有沒有新版本，到「⋯」→「設定…」按「檢查更新」（見[不連網的承諾](05-security-and-privacy.md#不連網的承諾)）。
- **解除安裝**：從 Windows 的「設定」→「應用程式」解除安裝。PDF 的檔案關聯會一起移除。
  - app 在這台電腦上保存的資料（設定、最近開啟的檔案等）在 `%LOCALAPPDATA%\io.github.winner0988.pdfreader`；要完全清除，解除安裝後刪除這個資料夾。
  - 記住的密碼存在 Windows 認證管理員，不在那個資料夾：解除安裝前先到「設定」的「記住的密碼」按「全部忘記…」。

## 設為預設的 PDF 閱讀器

安裝檔不會搶走 PDF 的預設程式；Windows 11 只讓你自己決定。

1. 開啟 PDF Reader，按工具列右邊的「更多」（⋯），選「設為預設 PDF 閱讀器」。
2. Windows 的「設定」會開到 PDF Reader 的頁面，把 `.pdf` 設為用它開啟。

開不了設定頁時，app 會說明手動的路徑：「設定」→「應用程式」→「預設應用程式」，搜尋「PDF Reader」。

沒有設為預設也可以用：在檔案總管的 PDF 上按右鍵，「開啟檔案」→「PDF Reader」。

## 開啟檔案

- 按「選擇檔案…（Ctrl+O）」或工具列的「開啟」，對話框中可以一次選多個檔案，每個檔案一個分頁。
- 把 PDF 從檔案總管拖到視窗裡。
- 從檔案總管雙擊（已設為預設時）。

開啟超過 0.3 秒時會顯示「正在開啟 <檔名>…」。打不開時顯示「無法開啟這個檔案」與原因；PDF 引擎出錯或沒有回應時有「重試」。

文件總是從第一頁開始：app 不記住你上次看到哪裡，以免留下閱讀紀錄。

## 分頁

- 每個檔案一個分頁，最多同時開 20 個；分頁記住自己的頁碼、縮放、旋轉、側欄與搜尋。
- 分頁列右邊的「＋」開啟檔案；✕、滑鼠中鍵或 `Ctrl+W` 關閉分頁。有未儲存的變更時會先問。
- `Ctrl+Tab`／`Ctrl+Shift+Tab` 切換分頁。
- 分頁名稱前有「•」表示有未儲存的變更。

## 最近開啟的檔案

沒有開啟文件時，畫面下方列出「最近開啟的檔案」，最多 20 筆，最新的在前。

- 清單只顯示檔名，不顯示資料夾；完整路徑只存在這台電腦上的 app 資料中。
- 每一筆右邊的 × 從清單移除；「清除清單」一次清除全部。
- 檔案已經不在時，app 會告訴你並從清單移除。
- **不想留下某個檔案的紀錄**：開啟它，在「⋯」選單勾選「不記錄此檔案」。之後再開也不記錄；取消勾選就恢復。
- **完全不記錄**：「⋯」→「設定…」，關閉「記錄最近開啟的檔案」。目前的清單會一起清除。
- 標記為機敏的文件一律不記錄（見[機敏文件](05-security-and-privacy.md#機敏文件)）。

## 有密碼的文件

開啟有密碼的文件時，分頁顯示「這份文件受密碼保護」與密碼欄。

1. 輸入密碼，按 `Enter` 或「解鎖」。欄位送出後立刻清空。
2. 密碼不對時顯示「密碼不正確，請再試一次。」
3. 「取消」關閉這個分頁。

以憑證加密等不支援的方式時，app 會說明無法開啟。

### 記住密碼

密碼欄下方有「記住這份文件的密碼（存在 Windows 認證管理員）」，**預設不勾**。

- 勾選後，密碼在**打開文件之後**才存，打錯的不存。之後開啟這份文件（搬移或改名的複本也一樣）就不必再輸入。
- 密碼存在 Windows 認證管理員，不在 app 的資料夾，也不在 PDF 檔案裡。**同一個 Windows 帳號的其他程式讀得到它**；共用的電腦上請不要勾。
- 用記住的密碼開啟時，文件上方有一條提示「已用記住的密碼開啟這份文件。」，按「忘記」就刪掉這份文件的密碼，下次開啟會再問。
- 也可以從「⋯」選單選「忘記這份文件的密碼」。
- 「⋯」→「設定…」的「記住的密碼」顯示記了幾份文件，「全部忘記…」一次刪除全部。這裡沒有逐項清單，因為記錄裡沒有檔名。
- 有些文件不能記住密碼（app 會說明原因），例如加密資料沒有可以查找的部分；這時文件照常開啟。
- 同一個密碼用在很多檔案時，每個檔案要各記一次。
