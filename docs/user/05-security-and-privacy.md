# 5. 安全與隱私

[回到目錄](README.md)

## 不連網的承諾

- app **不會自行連網**，不載入遠端資源，不自動更新。
- 唯一的連網：你在「⋯」→「設定…」的「更新」按下「檢查更新」時，向 GitHub 查詢一次最新的版本號碼。不會下載或安裝任何東西；GitHub 會看到你的 IP 位址與查詢的時間。
- 有新版本時出現「前往下載頁…」，和文件裡的外部連結一樣，先讓你確認完整網址，才交給瀏覽器開啟。
- 不收集任何使用者資料，不回報錯誤。
- 「⋯」→「關於」列出這些承諾、版本、授權（AGPL-3.0-or-later）與原始碼的位置；「第三方元件授權…」在 app 裡顯示，不連網。

## 已封鎖的內容

PDF 可以夾帶程式與自動動作，有些被用來攻擊或追蹤讀者。app 一律不執行它們，也**沒有「允許」的選項**。

文件含有這些內容時，工具列下方出現警示橫幅，例如「已封鎖此文件中的 2 項內容：JavaScript 腳本、開檔自動動作。這些內容不會執行。」按「詳細資訊」列出每一類：

| 類別 | 是什麼 |
|---|---|
| JavaScript 腳本 | 文件內嵌的程式碼 |
| 開檔自動動作 | 開啟文件時自動執行的動作 |
| 事件觸發動作 | 開啟頁面、輸入欄位等時機自動執行的動作 |
| 啟動外部程式 | 會開啟電腦上其他程式的動作 |
| 表單傳送 | 把表單內容送到網路或其他位置 |
| 匯入外部資料 | 從其他檔案讀取資料到表單 |
| 開啟其他文件 | 連到其他檔案或網路位置的文件 |
| 開啟內嵌文件 | 開啟文件內嵌的其他文件 |
| 遠端資源引用 | 從網路載入的圖片或檔案（可能用來追蹤開啟時間與 IP） |
| 網路共用路徑 | 指向 `\\伺服器` 的路徑；Windows 可能自動傳送帳號資訊，所以特別標示 |
| XFA 動態表單 | 舊式動態表單，可能包含腳本與網路傳送 |
| 多媒體內容 | 內嵌的影片、音訊或互動元件 |
| 內嵌附件 | 文件夾帶的其他檔案（不會自動開啟） |

✕ 關閉橫幅，只對這次開啟有效。

因為不執行腳本，有些表單的自動計算不會作用，有些文件也可能看起來少了互動功能；這是刻意的。

### 遠端資源引用的網址

文件引用網路上的圖片或其他文件時，app 永遠不會自行連網抓取（避免追蹤開啟時間與 IP）。

若想檢視那些內容，在工具列下方的警示橫幅按「詳細資訊」，在「可以在瀏覽器開啟的網址」下方列出找到的網址。按「在瀏覽器開啟…」，核對完整網址後按「開啟」，由預設瀏覽器開啟。開啟後，該網站會得知你的 IP 位址與存取時間。表單傳送位址、網路共用路徑與本機檔案不會列在此處，也不能開啟。

### 內嵌附件的取出

文件內嵌的附件不會自動執行。若要取出附件，可以在側欄切換到「附件」分頁，檢視所有附件並按「另存…」存到電腦中（見[側欄](02-reading.md#側欄：目錄、縮圖、附件與遮蔽)）。存下來的檔案會加上網際網路標記，app 永遠不會直接開啟任何附件。

## 外部連結

- **文件內的連結**（例如「前往第 5 頁」）直接跳頁。
- **網址**（`http`、`https`、`mailto`）：點下去會先出現「要開啟外部連結嗎？」，顯示網站名稱與**完整網址**。預設焦點在「取消」；確認後按「開啟」，才交給你的預設瀏覽器。瀏覽器會連上網路，對方可能因此得知你的 IP 位址。
  - 網址有非拉丁字母（可能是假冒的網站）或會改變文字方向的隱藏字元時，對話框會警告並顯示實際的網址。
  - 「複製連結」只複製，不開啟。
  - 沒有「永遠信任此網站」：每次都會問。
- **其他連結**（`file:`、網路共用路徑、啟動程式、開啟其他文件、腳本等）一律封鎖。點下去顯示「已封鎖這個連結」與原因，只能檢視與複製內容，**沒有「仍要開啟」**。

## 數位簽章與簽署

文件有數位簽章時，頁面上方出現簽章提示列。驗證在這台電腦上離線進行，不連網。

- **綠色**：簽章有效，簽署者受信任（憑證鏈接到這台電腦的 Windows 信任的根憑證）。
- **琥珀色**：簽章有效但無法確認簽署者是誰（例如自己簽發的憑證）、簽署之後文件又有變更，或本程式無法驗證。
- **紅色**：簽章無效：簽署之後文件被改動，或簽章與文件不符。不要相信這份文件是簽署者簽署的樣子。

按「簽章資料」看每個簽章的狀態、簽署者與簽署時間。注意：

- 「簽章有效」表示簽署之後內容沒有被改動，**不保證簽署者的身分**。
- 簽署時間是簽署者自己聲稱的，沒有時間戳記證明。
- 沒有檢查憑證是否已被撤銷。

有簽章的文件：儲存時以附加的方式寫入，保留原本的簽章；不能加密、壓縮、扁平化、標記為機敏或安全遮蔽；隱私匯出、分享前淨化與浮水印的副本中簽章不成立。

### 簽署文件

用你的憑證簽署目前的文件，另存成新副本，原檔不變。「⋯」→「簽署…」。

1. 選「簽署用的憑證」：
   - **「這台電腦的憑證（包含讀卡機裡的自然人憑證等卡片）」**：列出這台電腦憑證存放區中可用的憑證、簽發者與到期日。不能用的憑證（過期、尚未生效、不能用來簽署）會列出但無法選取。使用晶片卡時，先插入讀卡機後按「重新整理」；如果憑證需要 PIN，會由 Windows 或卡片的程式詢問，app 看不到 PIN。
   - **「憑證檔（.pfx 或 .p12）」**：按「選擇憑證檔…」選取檔案，並輸入「憑證檔的密碼」。
2. 設定「簽章的外觀」：
   - 「顯示在目前這一頁（第 n 頁）的角落」：選位置（「左上角」、「右上角」、「左下角」、「右下角」）。
   - 或選「不顯示在頁面上」。
   - 可在「原因（選填）」填寫簽署原因。
3. 按「選擇位置並簽署…」，選擇副本儲存位置（建議 `<檔名>（已簽署）.pdf`）。
4. 簽署完成後顯示「已簽署並存成新檔」，並在新分頁開啟簽好的文件。

注意：
- 簽署在本地離線進行，不連網；app 不會記住憑證檔或密碼。
- 簽署時間是這台電腦的時間，沒有時間戳記證明。
- 不能簽署的情況：已加密的文件、有尚未儲存的變更（先儲存再簽署）、認證簽章不允許變更的文件、開啟時經過修復的檔案。
- 自己簽發（自簽）的憑證，在別人的電腦上會顯示「有效但無法確認簽署者」。

## 文件權限

加密的 PDF 可以限制複製與列印。app 和 Adobe Acrobat 一樣遵守這些限制，狀態列在檔名後面列出，例如「已限制：不可複製、不可列印」。

| 作者的限制 | 結果 |
|---|---|
| 不可複製 | 可以選取，但不能複製或匯出 |
| 不可列印 | 「列印…」停用 |
| 只能低解析度列印 | 以 150 dpi 列印 |
| 不允許修改、註解或填寫表單 | 相關的編輯停用，標示「作者不允許」 |

## 機敏文件

把一份文件標記為機敏，可以減少它在這台電腦上留下的痕跡。

**標記後**

- 從這份文件複製的文字不會進入 Windows 的剪貼簿歷程（`Win+V`），也不會同步到雲端剪貼簿。
- 不會記錄在最近開啟的檔案，也不會進入本機全文索引。
- **防截圖保護**：開著機敏文件時，app 視窗不會出現在截圖、剪取工具、錄影、視訊會議的螢幕分享與遠端協助中（看到的是視窗後面的畫面）；畫面上照常顯示。狀態列顯示「防截圖：開」。這是整個視窗一起生效：開著機敏文件時，其他分頁也擷取不到。要分享螢幕，請先關閉機敏文件或取消標記。需要 Windows 10 2004 以後的版本；系統不支援時狀態列顯示「這台電腦無法阻擋螢幕擷取」。無法防範用相機實體拍攝，也無法阻擋具備系統管理員或核心權限的程式。
- **縮圖隱藏**：側欄的「縮圖」只顯示頁框與頁碼，不畫出頁面內容；點擊、選取、搬移頁面功能照常。注意：檔案總管與桌面的縮圖是 Windows 產生的，app 無法對單一檔案停用；若要避免，可在檔案總管的「資料夾選項」→「檢視」勾選「永遠顯示圖示，不顯示縮圖」，並以「磁碟清理」清除縮圖快取。
- 標記寫在**檔案本身**：搬移、改名、複製檔案都仍是機敏文件；隱私匯出的副本不是。
- 開著機敏文件時，狀態列顯示「機敏文件」。

**怎麼標記**

1. 開啟文件，「⋯」→「標記為機敏…」。
2. app 先檢查檔案，再說明會怎麼修改它：在檔案結尾附加一筆紀錄，原本的內容不變，但修改時間會改變。
3. 按「標記為機敏」。

- 加密的文件要輸入**權限密碼**（不是開啟密碼）。
- 不能標記的情況：有數位簽章、唯讀、有尚未儲存的變更、開啟後被其他程式改過。app 會說明。
- 取消標記：開啟它，「⋯」→「取消機敏標記…」。
- 「設定」的「機敏文件」列出在這台電腦上標記過的檔名（沒有路徑）。「移除」只是不再列出，檔案仍是機敏文件。

## 安全遮蔽

把看得到的內容（文字、圖片、圖形）從檔案中**真正刪除**，而不只是蓋一塊黑色。

**1. 標記要遮蔽的範圍**

- 按工具列的「安全遮蔽」，在頁面上拖曳框選；點一下放一個預設大小的方塊；`Esc` 結束。
- 或選取文字後，按右鍵選「標記為待遮蔽」。
- **找出個資**：在側欄「遮蔽」分頁按「找出個資…」（文件允許修改且沒有簽章時可用）。
  - 勾選搜尋類別：「身分證字號／新式居留證」、「手機號碼（09 開頭）」、「市話號碼」、「電子郵件」、「信用卡卡號」、「統一編號」，或輸入「自訂關鍵字」（不分英文大小寫）。號碼類別需符合檢查碼或長度規則。
  - 比對只在這台電腦的記憶體中進行。搜尋結果只顯示遮住中間的預覽與頁碼（上限 1,000 筆）。
  - 勾選欲遮蔽的項目，按「標記勾選項目（n）」轉為待遮蔽標記。之後仍需按「套用遮蔽…」並存檔，不會自動套用。
  - 限制：不辨識姓名與地址；掃描頁要先辨識文字才找得到；圖片裡的字找不到。
- 標記以紅框顯示「待遮蔽」，可以移動、縮放、刪除。這時還沒有刪除任何東西。

**2. 檢查清單**

側欄的「遮蔽」列出所有標記（依頁碼）。點一下跳到那裡；可以逐筆刪除或「全部刪除」。

**3. 套用**

按「套用遮蔽…」，確認對話框說明：

- 範圍內的其他註解與表單欄位（包括填的值）會一起刪除；
- **以下項目不會自動處理，請另行確認**：書籤標題與頁面標籤；縮圖與內嵌的檔案；標記結構的替代文字（ActualText）；文件資訊與 XMP 中繼資料（請用「隱私匯出」清除）；內嵌字型子集中的字形外框；
- 套用後可以復原，但只到存檔為止；
- 存檔不會抹除磁碟上舊檔案的位元組。

按「確認套用」。

**4. 儲存並驗證**

儲存時整份文件重寫，app 再讀一次寫出的檔案驗證：

- 成功：「已儲存，已遮蔽並驗證：寫出的檔案裡，遮蔽的範圍沒有文字，也找不到被移除的字。」
- 沒有通過驗證：app 會說明有幾處。**請先不要分享這個檔案**，改用「另存新檔」後再檢查。

要避免舊資料留在磁碟上：用「另存新檔」存成新檔案，再自己用安全抹除工具處理原檔案。有數位簽章的文件不能遮蔽。

## 這台電腦上保存的資料

「⋯」→「設定…」的「這台電腦上保存的資料」列出 app 存的所有東西，全部在 `%LOCALAPPDATA%\io.github.winner0988.pdfreader`：

- 最近開啟的檔案（完整路徑；畫面只顯示檔名）
- 設定
- 本機全文索引（在「設定」中勾選「建立本機全文索引」時才有）：以 DPAPI 加密儲存，只有你的 Windows 帳號讀得到；用來在所有開過的文件中搜尋。機敏文件、有密碼的 PDF、選了「不記錄此檔案」的檔案，以及隨身碟或網路位置上的檔案不會進索引；關閉此選項、關閉「記錄最近開啟的檔案」、清除最近開啟清單或按「清除索引」時立即刪除
- 在這台電腦上標記為機敏的檔名（不含路徑）
- 你匯入的 OCR 語言資料與字型
- 尚未儲存的變更（只在 app 沒有正常結束時留下，見[當機後還原](03-editing.md#當機後還原)）
- 畫面元件（WebView2）的暫存資料

這個資料夾不會同步到其他電腦，也不會上傳。關閉 app 後可以直接刪除它。記住的密碼不在這裡，在 Windows 認證管理員（見[記住密碼](01-install-and-start.md#記住密碼)）。

app 自己的開啟與另存對話框不會把檔案加進 Windows 的「最近使用的項目」與工作列的跳躍清單。從檔案總管雙擊開啟的檔案，是否記錄由 Windows 決定。
