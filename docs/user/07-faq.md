# 7. 常見問題與已知限制

[回到目錄](README.md)

## 常見問題

**安裝時 Windows 說「Windows 已保護您的電腦」，安全嗎？**
安裝檔目前沒有程式碼簽章，所以 SmartScreen 顯示「不明的發行者」。先用 `Get-FileHash` 核對雜湊值與 `.sha256` 檔相同，再按「其他資訊」→「仍要執行」（見[安裝](01-install-and-start.md#安裝)）。

**開檔時出現「已封鎖此文件中的…項內容」，這份文件有危險嗎？**
不一定。很多正常的文件也有 JavaScript 或自動動作，例如表單的自動計算。app 一律不執行這些內容，所以開啟、閱讀都是安全的。要特別注意的是「網路共用路徑」與「啟動外部程式」：正常的文件很少需要它們（見[已封鎖的內容](05-security-and-privacy.md#已封鎖的內容)）。

**表單的總計欄沒有自動算出來？**
自動計算是 PDF 裡的腳本，app 不執行腳本。請自己填入數字。

**掃描的文件不能搜尋或複製？**
掃描頁是圖片。app 預設會在背景辨識文字，辨識好的頁面就可以搜尋與複製；如果關掉了自動辨識，從「⋯」選單選「辨識此文件的文字」（見[掃描頁的文字辨識](02-reading.md#掃描頁的文字辨識)）。

**為什麼點連結要再確認一次？**
連結顯示的文字可以和實際的網址不同。確認對話框讓你看到完整的網址，再決定要不要交給瀏覽器（見[外部連結](05-security-and-privacy.md#外部連結)）。

**怎麼合併兩個 PDF？**
開啟第一個，在側欄的「縮圖」按右鍵，選「在後面插入其他檔案的頁面…」，選第二個檔案，再儲存（見[插入其他檔案的頁面](03-editing.md#插入其他檔案的頁面)）。

**怎麼拆分 PDF？**
「⋯」→「匯出…」，格式選「PDF 檔案（每幾頁存成一個檔案）」，或選「PDF 檔案（選的頁面存成一個新檔案）」只取出部分頁面（見[匯出](04-export-and-convert.md#匯出)）。

**怎麼把很多檔案一次加密或清除中繼資料？**
用「⋯」→「批次處理…」（見[批次處理](04-export-and-convert.md#批次處理)）。

**怎麼在所有開過的文件中搜尋？**
到「⋯」→「設定…」的「本機全文索引」開啟「建立本機全文索引」（需同時開啟「記錄最近開啟的檔案」）。之後按 `Ctrl+Shift+F` 或「⋯」→「在所有文件中搜尋…」，輸入文字即可跨文件搜尋開過的檔案內容，點擊結果能直接開檔跳頁（見[在所有文件中搜尋](02-reading.md#在所有文件中搜尋)）。

**怎麼簽署 PDF 文件？**
開啟未加密且已儲存的文件，從工具列「⋯」選單選「簽署…」。可以使用這台電腦的憑證（包含讀卡機裡的自然人憑證等晶片卡）或憑證檔（.pfx / .p12），選擇簽章顯示位置後另存為已簽署的副本（見[簽署文件](05-security-and-privacy.md#簽署文件)）。

**怎麼快速把文件中的身分證、手機或卡號遮蔽？**
開啟側欄切換到「遮蔽」分頁，按「找出個資…」。勾選身分證字號／新式居留證、手機號碼、信用卡卡號等類別或輸入自訂關鍵字，開始搜尋後勾選項目，按「標記勾選項目」，最後按「套用遮蔽…」並存檔（見[安全遮蔽](05-security-and-privacy.md#安全遮蔽)）。

**批次處理加 Bates 編號可以跨檔案連號嗎？**
可以。「⋯」→「批次處理…」選「頁碼與 Bates 編號」，Bates 編號會跨多個檔案依序連號，失敗或略過的檔案不會佔用號碼（見[批次處理](04-export-and-convert.md#批次處理)）。

**加密副本的密碼忘了怎麼辦？**
無法找回。app 不保存「加密並另存新檔」的密碼。原本的文件沒有被改變，可以重新加密一份。

**有簽章的文件存檔後，刪掉的頁面還在檔案裡？**
為了保留簽章，有簽章的文件以附加的方式儲存，舊的內容仍在檔案中（只是看不到）。要真的刪除內容，請用不保留簽章的副本（例如「隱私匯出」），並了解副本中的簽章不再成立。

**出現「PDF 引擎發生錯誤，已重新啟動」？**
每份文件由一個隔離的 PDF 引擎處理，它出錯時 app 會用新的引擎重新開啟文件，其他分頁不受影響，未儲存的編輯也不會遺失（以密碼開啟的文件要再輸入一次密碼，記住密碼的文件不用）。開檔時就出現這個訊息的話，按「重試」。一直出錯的檔案可能已損毀或是惡意的檔案。

**app 當機了，我的編輯還在嗎？**
下次開啟同一個檔案時，app 會問要不要「還原變更」（見[當機後還原](03-editing.md#當機後還原)）。

**怎麼完全清除 app 在這台電腦上留下的資料？**
關閉 app，刪除 `%LOCALAPPDATA%\io.github.winner0988.pdfreader` 資料夾；記住的密碼在「設定」按「全部忘記…」（見[這台電腦上保存的資料](05-security-and-privacy.md#這台電腦上保存的資料)）。

**怎麼回報問題？**
到 [GitHub 的 Issues](https://github.com/winner0988/Pdf-reader/issues) 說明怎麼發生的、用的版本（「⋯」→「關於」）。**不要附上私人的 PDF**；Issues 是公開的。

## 已知限制

**系統**

- 只支援 Windows 11（64 位元）。WebView2 被移除的電腦要自行安裝。
- 安裝檔沒有程式碼簽章，SmartScreen 會警告。
- 不會自動更新：要自己檢查並安裝新版本。

**開啟與閱讀**

- 以憑證加密的 PDF 打不開。
- 最多同時開 20 個分頁。
- 不記住上次讀到哪一頁（刻意的，以免留下閱讀紀錄）。
- 點連結跳頁之後，還沒有「回到上一個位置」。
- 辨識出的文字（OCR）只在記憶體中，不寫進檔案；一次只用一種語言。

**主動內容**

- PDF 裡的 JavaScript、自動動作、表單腳本一律不執行：自動計算、格式檢查與互動功能都沒有作用。
- 遠端資源、開啟其他文件、網路共用路徑的連結一律封鎖。
- 目前可以檢視與另存文件內嵌的附件，但 app 永遠不會直接開啟附件（以防止惡意程式執行，見[側欄：目錄、縮圖、附件與遮蔽](02-reading.md#側欄：目錄、縮圖、附件與遮蔽)）。

**編輯**

- 文字方塊不支援需要特殊排版的文字（阿拉伯文、希伯來文、印度系文字、組合記號），也不模擬粗體或斜體。
- 可變字型、彩色字型、PostScript（CFF）輪廓的字型不能用在文字方塊。
- 簽署文件使用電腦本機時間，目前尚無時間戳記（RFC 3161）伺服器驗證功能。
- 有數位簽章的文件不能加密、壓縮、扁平化、標記為機敏或安全遮蔽。

**轉檔與匯出**

- 匯出成 Word 只保留文字與圖片，不保留版面、欄位與表格。
- 從 Office 文件建立 PDF 是實驗性的，版面可能和原本不同；網頁轉 PDF 不載入遠端的圖片與樣式。
- 「加密並另存新檔」的限制（不允許列印、複製、修改）靠閱讀器自行遵守，有些程式會忽略。
- 批次處理會略過有密碼的檔案。

**安全遮蔽**

- 書籤標題、頁面標籤、縮圖、內嵌的檔案、替代文字、文件資訊與字型子集中的字形不會自動處理，套用前請自行確認。
- 存檔不會抹除磁碟上舊檔案的位元組。
