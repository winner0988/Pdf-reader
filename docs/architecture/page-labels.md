# 頁碼標籤（PageLabels，B5-07）

PDF 規格（ISO 32000-1 §12.4.2）允許文件在 Document Catalog 中以 `/PageLabels` 定義自訂頁碼標籤（如羅馬數字、字母、前綴或從特定數字開始編號）。本模組負責安全讀取、清理並在介面呈現文件頁碼。

## 走訪架構與安全防護

PDF 的 `/PageLabels` 結構為 Number Tree。為了防範惡意構造的文件造成資源耗盡或循環參照，worker 實作了自主的安全迭代走訪：

1. **節點與深度預算**：
   - 最大走訪深度 `MAX_PAGE_LABEL_DEPTH = 64`。
   - 最大走訪節點數 `MAX_PAGE_LABEL_NODES = 10,000`。
   - 超過預算或樹結構損毀時安全終止走訪，保留已成功解析的標籤區間。
2. **循環與 DAG 參照追蹤**：
   - 記錄所有已走訪的間接物件編號（`HashSet<i32>`），一旦偵測到重複物件立即跳過，避免循環或共享節點引發重複展開。
3. **金鑰驗證與單調性**：
   - 檢查起始頁碼索引金鑰：必須為整數、非負、小於 `page_count`，且嚴格大於前一筆金鑰（單調遞增）。
   - 不合規格的金鑰與標籤字典會被捨棄，確保區間邊界正確且不引發 panic。
4. **格式化演算法安全性**：
   - 支援羅馬數字（`/R`、`/r`）、英文字母（`/A`、`/a`）、十進位（`/D`）與自訂前綴（`/P`）。
   - 羅馬數字大於 3999 時自動回退為十進位字串。
   - 字母編號重複次數限制最多 64 字元。
   - 透過除法與餘數常數時間計算頁碼，運算時間不隨 `/St`（起始編號）數值增大而增長。

## 字串清理與 IPC 上限

從檔案讀出的頁碼標籤視為不受信任的外部字串，由 `crates/ipc_contract/src/text.rs` 進行嚴格過濾：

- **長度上限**：單一標籤 UTF-8 長度上限為 `MAX_PAGE_LABEL_BYTES = 64` 位元組。
- **字元清理**：清除 ASCII 控制字元（`\u{0000}..\u{001f}`、`\u{007f}`）、C1 控制字元（`\u{0080}..\u{009f}`）、雙向控制字元（Bidi embedding/override/isolate，如 `\u{202a}..\u{202e}`、`\u{2066}..\u{2069}`、`\u{061c}`）以及零寬字元（`\u{feff}`、`\u{200b}` 等），避免介面排版混亂或詐欺顯示。

## IPC 傳輸與記憶體預算

標籤在開檔時隨 `OpenedDocument` 一次性傳回：
- **一般文件**：無 `/PageLabels` 或標籤皆與 1-based 實體頁碼相同時回傳 `None`，不占用額外傳輸與記憶體。
- **最極端狀況**：在最大允許頁數 `MAX_PAGE_COUNT = 100,000` 頁且每頁皆達最大長度 64 位元組時，標籤陣列大小約 6.4 MB，遠低於單一 frame 限制 `MAX_FRAME_BYTES = 80 MiB`（< 8%）。
- 於開檔時一併取得，避免在使用者快速翻頁、滾動縮圖或即時搜尋時產生額外的 IPC 來回往返。

## 前端互動

1. **頁碼輸入框（Toolbar）**：
   - 當頁面有自訂標籤時，顯示標籤與實體總頁數（如 `iv` 與 `（4／120）`）。
   - 使用者輸入內容後優先進行精確、區分大小寫的標籤比對；若有多頁具備相同標籤，跳至第一處並於狀態列提示；若未比對到標籤，則回退解析為實體頁碼數字。
2. **縮圖側欄（Thumbnails）**：
   - 縮圖標題在自訂標籤與實體頁碼不同時，同時呈現兩者（如 `iv（4／120）`）。
3. **搜尋結果（SearchBar）**：
   - 搜尋命中結果在所在頁面具備自訂標籤時，於狀態顯示標籤與實體頁碼（如 `第 1／10 筆 · iv（4／120）`）。
