# 列印（MVP-17）

工作卡 [#72](https://github.com/winner0988/Pdf-reader/issues/72)；規格 §6「列印」。畫面見 [screen-map.md](../ux/screen-map.md) §7「列印」。

## 評估的兩種做法

| | A. 交給 WebView2 列印（採用） | B. Windows 的列印 API（GDI） |
|---|---|---|
| 做法 | worker 以列印解析度渲染頁面，前端把每頁放進只在列印時顯示的畫面，呼叫 `window.print()` | 主行程以 `PrintDlgEx` 取得印表機，逐頁向 worker 要點陣圖，以 `StretchDIBits` 送給印表機 |
| 對話框 | WebView2 的列印對話框：有預覽，可選印表機、頁面範圍、份數、直向／橫向、紙張與邊界，也能「另存為 PDF」 | Windows 傳統的列印對話框，沒有預覽 |
| 程式碼 | 只有前端；沿用既有的 `render_page`，**沒有新的 IPC、權限或 `unsafe`** | 主行程需要數百行 Win32 的 `unsafe` 程式碼（對話框、裝置內容、DIB） |
| 解析度 | 固定 200 dpi 的點陣圖 | 可依印表機解析度（例如 600 dpi）分段渲染 |
| 記憶體 | 所有要印的頁面先轉成 PNG 放在記憶體（每頁約數百 KB），所以一次最多 300 頁 | 一次只需要一頁 |
| 網路 | 都不經網路：印表機（包括網路印表機）由作業系統處理 | 同左 |

**採用 A**：沒有新的攻擊面（不增加 IPC、權限與 `unsafe`），對話框也比較好用（有預覽、另存為 PDF）。

它的限制：200 dpi 的文字在雷射印表機上不如向量清晰，而且一次最多印 300 頁。如果之後需要更高品質或更大量的列印，再以 ADR 評估 B。

## 流程

1. `Ctrl+P` 或「⋯」→「列印…」：app 的列印對話框選範圍，可以是全部、目前頁，或像 `1-3, 5` 的頁碼。
2. 逐頁向 worker 要點陣圖：
   - 200 dpi（`PRINT_SCALE = 200/72`）；
   - 不套用檢視用的旋轉與縮放，但保留 PDF 本身的 `/Rotate`；
   - 一次一頁，進度顯示在對話框中，可以取消。
   - 每頁轉成 PNG（blob URL，只在這個 WebView 的記憶體中），原始點陣圖隨即釋放。
3. 頁面放進 `[data-print-pages]`：
   - 它直接掛在 `<body>` 下；
   - 螢幕上看不到；
   - 列印時只印它（`index.css` 的 `@media print` 隱藏整個 app）；
   - 每頁一張紙，依紙張大小等比例縮放（`object-fit: contain`），所以混合尺寸的文件每頁都完整。
4. 圖片都解碼後呼叫 `window.print()`，開啟 WebView2 的列印對話框；印表機、份數、方向都在這裡選。
5. 對話框關閉（`afterprint`）後移除頁面，並釋放 blob URL。

## 安全與隱私

- **不經網路**：列印資料只在本機處理；網路印表機由作業系統處理。
- **點陣圖只在本機記憶體中**：PNG 以 blob URL 存在 WebView 的記憶體，列印結束就釋放。之後作業系統的列印多工緩衝處理會把列印工作暫存在磁碟上，這是 Windows 列印本身的行為，任何程式列印都一樣。
- **不會印出 app 本身**：沒有開啟文件時（或是展示用的假資料），`Ctrl+P` 什麼都不做，WebView 預設的「列印整個網頁」不會發生。
- **渲染快取**：列印的頁面經過主行程的渲染快取（以位元組數為上限的 LRU），可能暫時擠掉畫面上的頁面；之後捲動時會重新渲染。

## 驗證

- E2E（`tests/e2e/print.spec.ts`）：
  - 在真正的 app 中以 `benign/mixed-page-sizes.pdf`（A4、Letter、A3 橫向、200 × 200 pt）列印全部頁面；
  - `window.print` 改為記錄呼叫，不開啟系統對話框；
  - 檢查頁序與每頁的長寬比；
  - 列印媒體下看不到 app；
  - 以 CDP 的 `Page.printToPDF` 印出同一個畫面，剛好 4 頁。
- **以 Microsoft Print to PDF 實際列印**需要操作系統的對話框，請負責人在合併前手動確認一次（見 PR）。

## 尚未處理

- 自動把橫向的頁面轉向以配合直向的紙張：目前是等比例縮小。使用者可以在對話框中選橫向。
- 向量列印、超過 300 頁的單次列印（見上方 B）。
