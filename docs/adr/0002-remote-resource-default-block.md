# ADR 0002：遠端資源預設封鎖，並提供手動信任例外

## 狀態
已接受

## 背景
PDF 可以引用遠端圖片、字型等資源；不加防護的話，開啟檔案本身就可能在使用者不知情下對外發出請求，洩漏 IP 與開檔時間（「PDF 追蹤信標」）。這正是本專案最在意的「私人 PDF 外流」風險之一。但絕對封鎖、永不允許例外，會犧牲少數確實想讓遠端資源正常顯示的情境。

## 決定
所有 PDF 內部的遠端資源引用，預設一律封鎖，偵測到時於介面明確提示。使用者可以針對單一文件手動選擇信任（見 CONTEXT.md），允許該文件的遠端資源載入。信任狀態以文件內容雜湊值為依據，跨次啟動保留，內容一旦變動即失效。

## 後果
- 換來：保留使用者對自己信任文件的彈性，不會一刀切擋死所有情境。
- 付出：需要額外維護一份「已信任文件雜湊」清單；每一個信任例外都是一個潛在的外洩窗口，等於把一部分安全邊界交給使用者自己判斷。
