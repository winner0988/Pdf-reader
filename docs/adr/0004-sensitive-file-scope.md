# ADR 0004：系統層級外洩防護只套用在手動標記的文件

## 狀態
已接受

## 背景
縮圖快取關閉、剪貼簿處理等系統層級外洩防護，如果套用在所有 PDF，會讓一般不敏感的文件也失去縮圖預覽等原生體驗。使用者希望自己決定哪些文件需要加強保護。

## 決定
系統層級外洩防護預設不套用；使用者可以手動將特定文件標記為「機敏」（見 CONTEXT.md），只有被標記的文件才會啟用縮圖快取關閉、剪貼簿保護等措施。標記直接寫入該 PDF 自身的中繼資料，因此搬移或改名檔案都不會遺失標記。

## 後果
- 換來：一般文件維持原生的檔案總管體驗（縮圖、複製貼上都正常）。
- 付出：使用者必須自己記得標記，忘記標記的機敏文件不會被保護；比起「全部套用」的預設安全模型，這是刻意放寬到使用者主動管理。
- 付出：標記本身就是一個自訂中繼資料欄位；執行「隱私匯出」產生的副本會因為中繼資料被清除而不繼承此標記，但原始工作檔案上的標記不受影響（見 CONTEXT.md）。
