# ADR 0016：安全遮蔽是「標記範圍、套用、整份重寫」三步，只對沒有簽章的文件，並在存檔後驗證

## 狀態
提議中

（工作卡 #178〔B2-16〕。POC：`crates/pdf_worker/tests/redaction_poc.rs`。）

## 背景
- 規格 §3「安全遮蔽」：針對塗黑或刪除的敏感文字與圖片，必須從 PDF 二進位代碼中徹底移除，防止透過反組譯還原。目前 app 沒有任何這樣的功能。
- 在頁面上蓋一個黑框（註解或矩形）**不是**遮蔽：文字、圖片與向量圖形還在檔案裡，可以複製、搜尋或還原。要的是把它們真的拿掉。
- 相關決定：
  - ADR 0013：編輯在文件自己的 worker 記憶體中套用，可以復原到存檔為止；存檔時沒有簽章的文件整份重寫並丟掉不用的物件，已簽章的以增量更新附加（簽章仍成立，舊內容也還在）。
  - ADR 0014：簽章驗證。ADR 0015：掃描頁的辨識結果只存在 worker 的記憶體。B2-03 隱私匯出：清除中繼資料。B2-07：註解。
- MuPDF 1.27 有塗黑功能：頁面上的 Redact 註解標出範圍，`pdf_redact_page`（Rust 繫結：`PdfPage::add_redact_annotation`、`redact_with_options`）套用。

### POC 的發現
POC 是一頁有圖片、向量矩形與文字的 PDF：文字 `SECRET-ALPHA-123` 同時出現在頁面的文字、一個便條註解、一個表單欄位、一個連結、一個書籤與文件資訊（`/Info`）裡。範圍框住頁面上的那行文字，圖片與矩形各有一部分伸進範圍。

1. **範圍內的文字被移除**（`text_in_the_area_is_gone_from_the_page_and_from_the_rewritten_file`）：頁面的內容串流、文字擷取、搜尋與整份重寫後的檔案位元組都找不到；範圍外的兩行文字不變；選項 `black_boxes` 會在原處加一個黑框（內容串流多一個填色的路徑）。標記（Redact 註解）套用之後就沒有了（`the_marks_are_gone_once_they_are_applied`）。
2. **表單物件裡的文字與不可見的文字（例如 OCR 圖層）也被移除**（`text_in_a_form_object_and_invisible_text_are_removed_too`）；選項 `text: None` 才會留下。
3. **圖片只在範圍內失去像素**（`an_image_loses_its_pixels_in_the_area_only`）：範圍內的像素在圖片資料中被換掉（不只是上面蓋一個黑框），範圍外不變。
4. **「只蓋住」的選項會把內容留在檔案裡**（`an_option_that_only_covers_leaves_what_it_covers_in_the_file`）：圖片的方法選 `None`，圖片的原始像素還在，只是被黑框蓋住；向量圖形選 `None` 或 `RemoveIfCovered`（只移除完全在範圍內的），一個只有一部分伸進範圍的矩形仍在內容串流裡；只有 `RemoveIfTouched`（碰到就移除）把它移除。
5. **舊的內容串流在什麼情況下還在檔案裡**（`the_old_content_stays_in_the_file_unless_it_is_rewritten_with_garbage_collection`）：套用之後被取代的內容串流是沒人用的物件。不整理垃圾地寫出，它還在檔案裡；以增量更新附加（已簽章的文件存檔的方式）時整份舊的位元組都還在；整份重寫並整理垃圾（`garbage`，目前沒有簽章的文件存檔的方式）才會消失。
6. **範圍沒有碰到的東西還在**（`what_the_area_does_not_reach_stays_in_the_file`）：範圍內的便條註解與表單欄位的值、書籤的標題、文件資訊都還在檔案裡。範圍內的連結會跟著被移除。

沒有測試、也就沒有發現的：中文字與嵌入字型（同一條移除字形的路徑，實作時要補測試）、旋轉過的頁面的座標、掃描頁（圖片塗掉像素之後，worker 記憶體裡的 OCR 文字要丟掉）。

## 選項

| 選項 | 內容 | 代價 |
|---|---|---|
| **A. MuPDF 的 Redact 註解與 `pdf_redact_page`（建議）** | 標記與套用分開；套用時移除文字、圖片像素與碰到的向量圖形 | 範圍以外的洞（見下）要自己處理與說明；行為由 MuPDF 決定，要用 POC 的測試鎖住 |
| B. 自己改內容串流 | 解析內容串流、自己移除範圍內的運算 | 要自己處理字型、文字矩陣、形狀、轉換、表單物件、各種圖片編碼：很大，而且每一種遺漏都是洞 |
| C. 把頁面轉成圖片再蓋黑框 | 整頁點陣化 | 最保險，但文字不能搜尋與選取、檔案變大、其他頁面或選項要分開；可以之後當成「保守模式」另提 |
| D. 只蓋黑框 | 加一個黑色註解或矩形 | **不採用**：不是遮蔽 |

## 決定

### 標記與套用（選項 A）
- **標記**是一個編輯：`Edit::AddRedaction { page, rect }` 在頁面上加一個 Redact 註解（紅色外框、半透明，說明「待遮蔽」）。和其他註解一樣可以選取、移動、刪除，記在編輯歷程與崩潰復原日誌中（日誌只有範圍，沒有被遮蔽的內容）。可以框選文字、框選任意範圍，之後也可以由搜尋結果一次標記。
- **套用**是另一個編輯：`Edit::ApplyRedactions`，一定經過確認對話框（說明下面的「範圍之外」）。worker 對有標記的頁面以這組選項套用：黑框（使用者看得到哪裡被遮蔽）、圖片塗掉範圍內的像素、向量圖形碰到就移除（`RemoveIfTouched`）、文字移除（含不可見的文字與表單物件裡的）。不使用「只蓋住」的選項（POC 4）。
- 套用之後，範圍內的**其他註解與表單欄位**（便條、螢光筆、欄位的值）也一併刪除（POC 6）；對話框先說明有幾個。
- 套用可以**復原到存檔為止**（ADR 0013）：復原從 worker 保留的原始位元組重新開啟並套用其餘的編輯。存檔之後，檔案裡已經沒有被遮蔽的內容，無法復原；對話框這樣說明。

### 範圍之外：哪些不會被自動移除
| 位置 | POC | 處理 |
|---|---|---|
| 範圍內的連結 | 一併移除 | — |
| 範圍內的其他註解、表單欄位 | 留下 | 套用時刪除（上述） |
| 書籤標題、頁面標籤、縮圖、內嵌的檔案、標記結構的 `ActualText`、文件資訊與 XMP | 留下 | **不自動處理**：它們與範圍無關，不知道哪個是敏感的。套用的對話框與完成後的說明列出這些；中繼資料用隱私匯出（B2-03）；書籤與其他的，實作卡決定要不要提供「在書籤中尋找這段文字」 |
| 掃描頁的 OCR 結果（ADR 0015） | 只在 worker 記憶體 | 套用時丟掉那一頁的結果並重新辨識（影像已塗掉像素） |
| 字型的子集 | 留下 | 字形外框與字元對照表仍有被遮蔽的字元（沒有順序）；寫進說明，不處理 |
| 磁碟上舊檔案的位元組 | — | 存檔是先寫暫存檔再取代原檔，不會抹除磁碟上舊檔案的內容；要避免，請「另存新檔」，再自行以安全刪除工具處理原檔。說明裡寫明 |

### 存檔（沒有簽章的文件）
- 套用過的文件存檔一律**整份重寫並整理垃圾**（ADR 0013 對沒有簽章的文件本來就是這樣，POC 5）；實作時加測試鎖住（套用、存檔、重新開啟，內容與位元組裡都沒有被遮蔽的文字）。
- **已簽章的文件拒絕遮蔽**：增量更新會留下整份舊內容，重寫又讓簽章失效（比照扁平化與加密）；對話框說明，請使用者先處理簽章。作者不允許修改的文件（MVP-19）照樣不能遮蔽。

### 存檔後驗證
- 套用時，worker 在記憶體中記下範圍內被移除的文字；存檔之後，worker 把寫出的位元組重新開啟，檢查那些範圍內沒有任何文字、整份文件的文字擷取也找不到被移除的字串；驗證完就丟掉這些字串。
- 通過時狀態列說「已遮蔽並驗證」；沒通過時**不說完成**，說明檔案可能仍含有被遮蔽的內容，並提示另存新檔後再檢查。驗證只能保證文字；圖片與圖形靠上面的選項。

## 後果
- 換來：
  - 遮蔽是真的：文字、圖片像素與碰到的向量圖形從檔案中拿掉，舊內容不留；
  - 用的是 MuPDF 既有的功能，沒有新依賴，沙盒不放寬（worker 本來就改寫文件）；
  - 範圍之外的洞都有名字，使用者在套用前就知道。
- 付出：
  - 行為由 MuPDF 決定：升級 MuPDF 要重跑 POC 的測試；
  - 已簽章的文件不能遮蔽；
  - 文件層級的敏感內容（書籤、中繼資料）要使用者另外處理；
  - 套用之後的存檔慢一些（整份重寫，加上驗證時重新開啟）。
- 之後若要改變這個決定：「保守模式」（選項 C）可以另外加，不影響標記的介面；若 MuPDF 不再符合 POC，換成選項 B 只換 worker 內的一個模組。
- 實作要另開卡：標記工具與面板、套用的確認對話框與報告、`Edit::AddRedaction`／`ApplyRedactions` 的契約與驗證、worker 的套用與驗證、掃描頁、中文字與旋轉頁面的測試、E2E（標記、套用、存檔、重開、搜尋找不到、位元組裡沒有）。
