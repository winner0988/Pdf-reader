# ADR 0006：加密檔案密碼交由系統憑證庫記住

## 狀態
已接受

## 背景
使用者可能有多份自己加密的 PDF，每次都手動輸入密碼會造成日常使用的摩擦。但本專案的隱私原則是盡量減少任何形式的機密資料留存。

## 決定
密碼記憶功能委託給作業系統原生的憑證庫（Windows Credential Manager / macOS Keychain），不由本應用程式自行儲存或管理密碼明文。憑證庫的查找鍵使用文件識別碼（見 CONTEXT.md），而非檔案路徑或密碼內容本身，因此搬移、改名檔案都不影響密碼記憶功能——與機敏標記共用同一套識別機制。

## 後果
- 換來：日常開啟自己常用的加密檔案不需要每次輸入密碼；文件識別碼機制被機敏標記與密碼記憶兩個功能共用，降低系統整體複雜度。
- 付出：憑證庫本身成為一個新的信任邊界——若使用者的作業系統帳號被入侵，憑證庫裡的密碼就可能被存取；這是作業系統本身的安全模型，並非本應用程式引入的新弱點，但仍值得記錄在案。
- 需要針對 Windows／macOS（未來可能還有 Linux）分別串接不同的憑證庫 API，是一塊額外的跨平台維護成本。
