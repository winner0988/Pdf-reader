# ADR 0009：預設網路政策

## 狀態
提議中

（負責人於 2026-09-24 選擇選項 B，見工作卡 DEC-01（#1）；本 ADR 記錄這個決定，待負責人改為「已接受」。）

## 背景
規格書同時要求「完全離線運作、不串接任何外部 API」、「透過 GitHub Releases API 檢查更新」，以及「使用者信任的文件可以載入遠端資源」（ADR 0002）。這三條彼此衝突，必須明訂應用程式在什麼情況下可以連網，否則 agent 會各自解讀。

補充事實：MuPDF 本身不會主動下載 PDF 內引用的遠端資源；如果要「信任後載入」，需要另外寫一個下載器，等於新增一條連網路徑。另外，使用者確認後交給系統瀏覽器開啟的連結，是瀏覽器連網，不是本應用程式連網。

## 選項
- **A. 完全零網路**：應用程式沒有任何連網程式碼。更新由使用者自行到 GitHub 下載；遠端資源永遠只偵測、封鎖、提示。
- **B. 預設零網路，只允許使用者手動觸發的單一請求**：設定頁提供「檢查更新」按鈕，按下才連到 GitHub Releases，只送最基本的 HTTP 請求，不帶任何識別碼；不做自動檢查。遠端資源先維持只封鎖、只提示。
- **C. 自動檢查更新**：啟動時自動連網。違反「開檔不連網」的精神，不建議。

## 建議
採用 **B**，並將「信任後載入遠端資源」延後到確實有需求時再做（屆時另立 ADR，並規定下載只能由主行程執行、只能針對已信任文件）。MVP 期間等同 A：程式碼中不得有任何連網能力。

## 決定
採用 **B：預設零網路，只允許使用者手動觸發的更新檢查**。

- **預設**：
  - 應用程式不連網：開檔、渲染、搜尋、掃描、啟動、關閉都不發出任何網路請求；
  - 沒有自動、定期或背景的網路請求。
- **唯一的例外：手動檢查更新**
  - **何時**：只在使用者於設定頁按下「檢查更新」時，每按一次一個請求。不在啟動時檢查、不定期檢查、失敗不自動重試。
  - **誰發出**：只有主行程（Rust）。
    - WebView 永遠沒有網路能力：CSP 的 `connect-src` 不允許任何外部網址，也沒有 HTTP 外掛；
    - `pdf_worker` 也沒有：它在沒有網路 capability 的 AppContainer 中執行。
  - **連到哪裡**：固定的 HTTPS 網址，也就是本專案 GitHub Releases 的最新版本 API（`api.github.com`），不接受其他網址。
  - **送出什麼**：
    - 一個 GET 請求，只帶 GitHub 要求的固定 `User-Agent` 與 `Accept` 標頭；
    - 不帶 cookie、權杖、裝置或使用者識別碼，也不帶文件或使用紀錄。
    - GitHub 會看到使用者的 IP 位址與請求時間，這是連網本身無法避免的，按鈕旁要說明。
  - **收到之後**：
    - 只比對版本號，顯示「已是最新版本」或「有新版本」與下載頁的連結；
    - **不自動下載、不自動安裝**。下載頁與其他外部連結一樣，經使用者確認後才交給系統瀏覽器開啟。
- **實作時機**：
  - 「檢查更新」按鈕另開工作卡，並需要 `needs-security-review`；
  - 在那之前，程式碼中沒有任何連網能力，CI 的禁用清單照常執行；
  - 實作時才在 `scripts/ci/forbidden-patterns.txt` 中為主行程的 HTTP client 開一個明確的例外，並限制只能在單一模組中使用。
- **遠端資源（ADR 0002 的「信任後載入」）**：
  - 延後，直到確實有需求時再另立 ADR；
  - 屆時規定：下載只能由主行程執行，而且只針對使用者已信任的文件。
  - 在那之前，PDF 中的遠端資源永遠只偵測、封鎖、提示（MVP-11），沒有「信任後載入」；
  - ADR 0002 的其他部分（預設封鎖、偵測後提示、以內容雜湊判斷信任）不變。
- **不算本應用程式連網**：使用者確認後交給系統瀏覽器開啟的連結，由瀏覽器連網。

## 後果
- **換來**：
  - 開檔與閱讀永遠不連網，「PDF 追蹤信標」與自動更新都無法洩漏開檔行為；
  - 使用者仍然有官方的方式知道有新版本。
- **付出**：
  - 使用者要自己按「檢查更新」，安全修補的散布比自動更新慢；
  - 「信任後載入遠端資源」這個功能延後。
- **在「檢查更新」實作之前**：所有 PR 仍依選項 A 執行，不得引入 HTTP client、updater 或具網路能力的 Tauri 外掛（CI 的 `scripts/ci/forbidden-patterns.txt` 會擋下）。
- **同步的文件**：
  - 規格書 §1「無追蹤更新」、§3「完全離線運行」與「遠端資源載入防護與信任機制」（中英文）已依本決定更新；
  - ADR 0002 已接受，依規則不改內容，它的「信任後載入」由本 ADR 延後。
