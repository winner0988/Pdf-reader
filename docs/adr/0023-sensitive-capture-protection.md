# ADR 0023：開著機敏文件時，主視窗排除在螢幕擷取之外

## 狀態
提議中

（工作卡 B3-13（#301），B3 擴充 E1，見 `docs/planning/2026-10-20-plan-to-nov-20.md`。擴充 ADR 0004 的保護範圍。負責人決定選項。）

## 背景
- ADR 0004（已接受）：系統層級外洩防護只套用在使用者手動標記為「機敏」的文件。目前做到的是剪貼簿保護、縮圖與最近使用的檔案（B3-05）。
- 螢幕擷取是很常見、卻還沒擋的外洩管道：PrintScreen、剪取工具（Win+Shift+S）、錄影、視訊會議的螢幕分享、遠端協助，以及會定時擷取畫面的系統功能。
- Windows 10 2004 起有 `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`：畫面上照常顯示，但經由系統的擷取介面拿到的這個視窗是空白或黑色。它以**頂層視窗**為單位，無法只排除視窗中的一塊。
- 主行程已依賴 `windows-sys` 的 `Win32_UI_WindowsAndMessaging`，不需要新的依賴。
- app 是單一視窗、多分頁（ADR 0012）。

## 選項

| 選項 | 內容 | 代價 |
|---|---|---|
| A. 不做 | 說明擷取不受保護 | 機敏文件經由截圖或會議分享外洩 |
| **B. 只要有一個機敏分頁開著，整個主視窗都排除（建議）** | 開啟或標記機敏文件時設定，最後一個機敏分頁關閉或取消標記時恢復 | 這段期間其他非機敏分頁也擷取不到 |
| C. 只在機敏分頁是目前分頁時排除 | 切換分頁時跟著切換 | 切換的瞬間可能被擷取到；分享螢幕時畫面忽黑忽亮 |
| D. 所有文件都排除 | 不分機敏與否 | 違反 ADR 0004「預設不套用」的精神，使用者無法擷取一般文件 |

## 決定（選項 B）
- 主視窗與 app 的其他視窗（例如列印預覽），在「至少有一個開著的分頁是機敏文件」時設為 `WDA_EXCLUDEFROMCAPTURE`；條件不成立時設回 `WDA_NONE`。
- 時機：在機敏文件的**第一個畫面顯示之前**設定（開檔、復原、標記為機敏）；最後一個機敏分頁關閉或取消標記之後才恢復。
- 狀態列顯示「防截圖：開」，滑鼠移上去說明原因與限制。
- 設定失敗（例如舊版 Windows）：顯示警告「這台電腦無法阻擋螢幕擷取」，文件照常開啟。

### 限制（寫進使用說明）
- 擋不住用手機拍螢幕，也擋不住有系統管理員或核心權限的程式。
- 開著機敏文件時，螢幕分享與遠端協助看到的是空白；要分享就先關閉機敏文件或取消標記。
- 放大鏡等輔助工具是否受影響，在 POC 中確認；受影響就在說明中寫清楚。

### POC（接受前）
1. 開著機敏文件時，PrintScreen、剪取工具與 Windows.Graphics.Capture 拿到的視窗內容是空白；關閉後恢復。
2. 列印預覽等其他視窗同樣排除。
3. 放大鏡（全螢幕與鏡頭模式）下的行為記錄下來。
4. 在 CI 上以擷取 API 自動驗證（本機不做桌面擷取）。

## 後果
- 換來：機敏文件多擋一條最常見的外洩管道，不新增依賴，程式碼集中在主行程的一個小模組。
- 付出：
  - 使用者想刻意截圖機敏文件也做不到（要先取消標記）；
  - 開著機敏文件時，其他分頁也擷取不到；
  - 輔助工具可能受影響（POC 確認）。
- 與其他 ADR 的關係：擴充 ADR 0004 的保護清單；ADR 0012（單一視窗、多分頁）決定了只能整個視窗一起排除。
- 之後若要改變：改成選項 D（所有文件）或加一個設定開關，要另寫 ADR。
