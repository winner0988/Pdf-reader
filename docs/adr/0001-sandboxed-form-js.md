# ADR 0001：允許沙盒化表單 JavaScript，而非完全禁用

## 狀態
已接受

## 背景
專案的隱私核心原則是預設關閉所有主動內容（JavaScript、OpenAction/AA），因為這類機制是 PDF 最隱蔽的外洩管道之一。但使用者需要能操作依賴 JS 邏輯做自動計算的互動表單。

## 決定
表單相關的 JavaScript 執行預設關閉，但保留一個受限的例外：表單腳本沙盒（見 CONTEXT.md）。/OpenAction、/AA 等開檔即自動觸發的動作，無論如何一律停用，不受此例外涵蓋。

## 後果
- 換來：可以正常使用依賴計算欄位的複雜表單。
- 付出：JS 執行引擎本身仍是一塊需要維護與稽核的攻擊面，即使受限；沙盒若被引擎本身的漏洞繞過，風險依然存在，只是被大幅縮小。
- 若之後改為完全禁用，表單自動計算功能會直接失效，需另外設計替代方案（例如手動計算按鈕）。
