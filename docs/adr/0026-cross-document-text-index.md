# ADR 0026：跨文件的全文索引：預設關閉，只收開過的檔案，加密存在本機；機敏文件與有密碼的 PDF 不進索引

## 狀態
提議中

（工作卡 B3-11，[#242](https://github.com/winner0988/Pdf-reader/issues/242)。負責人 2026-10-21 對 D1 的決定：先做 A〔單一文件、只在記憶體〕，之後做 B〔跨文件、索引存磁碟〕，機敏文件不進索引，B 另寫 ADR。見 `docs/planning/2026-10-20-plan-to-nov-20.md`。）

## 背景
- 規格 §6「全文搜尋（建立本地索引，含 OCR 產生的隱藏文字層）」。D1 的 A（#242）讓開著的文件第二次以後的搜尋直接用 worker 記憶體裡的文字，關閉就沒了。使用者還想要「我記得某份文件裡有這句話，是哪一份？」：跨文件、關掉 app 之後還在的索引。
- **索引就是文件文字的副本。** 它比文件活得久：文件刪掉、搬走、遮蔽之後，索引裡可能還有原來的字；它在 `%LOCALAPPDATA%` 裡，會被備份、被同一個 Windows 帳號下的程式讀到，SSD 上刪掉的區塊也不一定真的消失。這和產品「注重隱私」的承諾直接相關，所以要 ADR。
- 機敏文件（CONTEXT.md、ADR 0004）的標記寫在檔案裡（`/PdfReaderDocumentId`），**要開檔才知道**一份檔案是不是機敏；B3-05 已經在 main 上，負責人「能標注機密文件之後再做 B」的前提已經成立。
- 有密碼的 PDF：使用者用密碼保護了內容；如果索引只靠 Windows 登入就能讀，等於繞過了那個密碼。
- 現有的本機資料（`docs/architecture/local-data.md`）只有主行程讀寫、先寫暫存檔再換名、有大小上限、可以從設定頁清除，**都沒有加密**；最大的隱私項目是 `recent.json` 的完整路徑（[#73](https://github.com/winner0988/Pdf-reader/issues/73) 的決定：路徑只存在本機，前端只拿到檔名與代號）。
- 不連網、零遙測（AGENTS.md 原則 1、2）；只有 worker 解析 PDF（ADR 0008）。

## 選項

| 選項 | 內容 | 代價 |
|---|---|---|
| A. 不做跨文件索引 | 維持 D1 A | 找「哪一份文件」只能一份一份開 |
| **B. 開過的檔案才進索引；預設關閉；加密存放（建議）** | 見「決定」 | 沒開過的檔案找不到；要寫加密與清除 |
| C. B 再加上使用者指定的資料夾，背景建立與更新 | 像 Windows 搜尋：指定資料夾裡的 PDF 都進索引 | worker 要在背景開啟使用者沒開過的檔案（含惡意檔）；要列舉資料夾、偵測變更、排程與限制資源；每個檔案都要開過才知道是不是機敏。可以之後在 B 上加，另寫 ADR |
| D. 明文索引（例如 SQLite FTS），預設開啟 | 最快、最簡單 | 文件文字以明文留在磁碟，使用者不知道；違反「注重隱私」的預設 |

## 決定（選項 B）

### 開關
- 設定頁新增「建立本機全文索引」，**預設關閉**。開啟時說明：「索引是文件文字的副本，加密存在這台電腦上，只有你的 Windows 帳號讀得到。機敏文件與有密碼的 PDF 不會進索引。」
- 關閉時**立即刪除整個索引**（先刪金鑰，見下方）。
- 「記錄最近開啟的檔案」關閉時，索引也停用並刪除；標記「不記錄此檔案」的檔案不進索引，已在索引裡的立即移除。索引不會比最近開啟的檔案記得更多。

### 什麼會進索引
- **只有使用者在 app 中開啟過的檔案**（不掃描資料夾、不跟著最近開啟的清單去開檔）。
- 內容是每一頁的文字層，與搜尋用的同一份（含 OCR 辨識的文字與 app 的文字方塊的字，#242）；不含註解內容、表單欄位值、附件、中繼資料。
- **不進索引**：機敏文件；有開啟密碼的 PDF；從崩潰復原開啟、還沒存檔的內容；以唯讀暫存方式開啟的檔案（例如附件，ADR 0025 本來就不開啟）。
- 索引反映**磁碟上的檔案**，不含未儲存的編輯。

### 何時建立與更新
- 開檔後，主行程在閒置時一頁一頁向該文件的 worker 要文字（低優先，有渲染或使用者操作就讓路，與 #242 的預先建立相同）；文件關閉時停止，已建立的頁面保留，下次開啟時補完。
- 以「完整路徑＋大小＋修改時間」辨認檔案；三者有一項不同就當成新的內容，舊的項目刪除後重建。
- **存檔取代原檔時立即刪除**該檔的項目，再重建（例如套用遮蔽後存檔，遮掉的字不能留在索引裡）。
- 使用者把文件標記為機敏時立即刪除它的項目；開檔時發現是機敏文件或有開啟密碼，也立即刪除該路徑的項目。

### 存放
- 位置：`%LOCALAPPDATA%\io.github.winner0988.pdfreader\index\`，只有主行程讀寫，照 `local-data.md` 的規則（暫存檔再換名、有大小上限、壞掉就當成沒有）。
- **加密**：主行程產生隨機的 256 位元金鑰，以 DPAPI（`CryptProtectData`，目前使用者）保護後存在 `index\key`；索引內容以 AES-256-GCM（Windows CNG）加密。不新增 crate；需要的 `windows-sys` 功能（`Win32_Security_Cryptography`）照依賴變更送安全審查。
- **清除**：先刪 `index\key` 再刪其他檔案。SSD 上的殘留區塊沒有金鑰就讀不出來。
- 上限：最多 2,000 份文件、全部 256 MiB（加密後）、每份 16 MiB 文字（超過的部分不進索引，結果上註明「只收錄前面的頁面」）；超過時刪掉最久沒開的文件的項目。實際格式（逐份的文字區塊或倒排索引）在架構文件決定，驗收：2,000 份、每份 100 頁的語料，全部搜尋 ≤ 1 秒。

### 搜尋與結果
- 新的「在所有文件中搜尋」：比對在主行程，用與單一文件搜尋相同的摺疊規則與 KMP（不解析 PDF，只比對 worker 先前交出的文字）。
- 結果給前端：**檔名、不透明代號**、頁碼、命中數、命中前後的一小段文字（截斷）；**沒有路徑**（與最近開啟的檔案相同，#73）。按下結果由主行程用存著的路徑開檔並跳到那一頁；檔案不在或已變更時告知並刪除那一項。
- 搜尋字串與結果不寫日誌、不進復原日誌。

### 設定頁「這台電腦上保存的資料」
- 列出索引：文件數、大小、「清除索引」按鈕；`local-data.md` 的表格加一列。

## 後果
- 換來：跨文件找字；預設不改變任何人的磁碟內容；開了也有加密、機敏與有密碼的檔案不進去、可以一鍵清除，與最近開啟的檔案一致的隱私規則。
- 付出：主行程新增加密存放與索引的程式碼、設定與畫面；worker 不變（用 #242 的頁面文字請求）；`needs-security-review`（新的本機資料、加密、`windows-sys` 的功能）。
- 擋不到的：
  - 以同一個 Windows 帳號執行的惡意程式可以呼叫 DPAPI 解開金鑰；
  - 使用者在別的程式中把檔案標記為機敏之前，那份檔案的文字已經在索引裡，要等下次在 app 中開啟才會刪除；
  - 刪除只是盡力而為：檔案系統的快照與備份可能有舊的加密內容（沒有金鑰仍讀不出來，但金鑰沒換之前的備份可以）。
- 不改變：沒有網路；只有 worker 解析 PDF；前端拿不到路徑。
- 規格 §6 在接受時補一句：「跨文件的索引預設關閉，見 ADR 0026」；CONTEXT.md 若需要「索引」一詞再補。
- 之後若要掃描資料夾（選項 C）、讓之後的離線 AI 讀取索引，或改變加密方式，都要另寫 ADR。
