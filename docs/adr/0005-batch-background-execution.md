# ADR 0005：批次處理可在背景／系統列繼續執行

## 狀態
已接受

## 背景
批次處理（中繼資料清除、EXIF 清除、浮水印、加密）處理大量檔案時可能耗時較長，強制使用者把主視窗開著等待，體驗不佳。但專案的核心原則之一是零背景常駐服務（無遙測），需要明確劃清這個背景執行機制跟被禁止的背景監控/回報行為的界線。

## 決定
批次處理佇列啟動後，允許使用者關閉主視窗，佇列在背景（以系統列圖示顯示進度）繼續執行，完成後跳出通知。此背景執行僅限於「批次處理背景服務」（見 CONTEXT.md）所定義的範圍。

## 後果
- 換來：使用者不需要死守著主視窗等批次跑完，可以去做別的事。
- 付出：需要實作系統列圖示、背景行程的生命週期管理，增加一塊需要維護與稽核的程式碼；系統列圖示本身是個新的 UI 元素，需要讓使用者一眼看出這不是遙測或監控。
- 之後如果想拿掉背景執行改成純前景阻塞，會影響已經依賴這個能力設計的批次佇列 UI。
