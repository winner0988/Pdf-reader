# Acrobat Pro 功能對照清單

> 依 2026-11-04 的 `main`（`f33eec4`，0.2.0 之後）整理。功能合併、開卡或決定不做時，在同一個 PR 更新這份清單。

負責人 2026-11-03：這個專案的目標是**開源的 Adobe Acrobat Pro 替代品，隱私優先**。這份清單把 Acrobat Pro（Windows 桌面版）的功能逐項列出，對照這個 app 有什麼、缺什麼、哪些因為隱私原則不做，作為 1.0 之後規劃每一批工作的依據。

隱私原則（[AGENTS.md](../../AGENTS.md)「不可違反的原則」，規格 §1、§3）是限制，不是可以拿來交換的條件：需要連網、雲端、帳號、遙測，或要執行文件裡主動內容的功能，就算 Acrobat 有，這裡也標「不做」；可以改成離線做法的，寫出替代方案。

### 這個 app 的特色

- 不連網（唯一的例外是使用者按「檢查更新」時查一次版本號碼）、零遙測、不需要帳號；Acrobat Pro 要登入 Adobe 帳號，也有雲端功能。
- 文件裡的 JavaScript 與開檔自動動作一律不執行；Acrobat 預設啟用 JavaScript。
- 註解不寫入作者與時間；Acrobat 會寫入作者名稱與時間。
- 每份文件各自一個沙盒 worker，一份惡意的 PDF 碰不到其他文件（ADR 0008、0012）。
- 機敏文件：不進最近開啟的檔案與全文索引，複製的文字不進剪貼簿歷程，視窗不出現在截圖、錄影與螢幕分享中（ADR 0004、0023；需要 Windows 10 2004 以後，擋不了相機拍攝與有系統管理員權限的程式）。
- 找出個資時認得台灣的身分證字號、新式居留證與統一編號，並驗證檢查碼。
- 開源（AGPL-3.0）、免費。

## 怎麼維護

- 功能合併的 PR 同時更新這份清單的那一列（「我們」與「卡」）；開卡時把卡號填進「卡」。
- 「不做」的列牽涉原則，要改先有 ADR。
- 每一批的計畫從「缺口排名」挑；挑完、做完後更新排名與摘要的數字。
- 參考：另一個以 Acrobat Pro 為目標的開源專案 [pdfcraft](https://github.com/storytold/pdfcraft) 有更細的自評（它的 `docs/target-app-parity.md`），但它不以隱私為先，例如啟動時會連網檢查更新、在主行程執行表單的 JavaScript。
